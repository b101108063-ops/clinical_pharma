## β 受器拮抗劑

### β₁、β₂ 阻斷 (Non-cardio-selective)

| 學名 | 其他 | 適應症 | 副作用、禁忌症 |
|------|------|--------|----------------|
| Nadolol | T₁/₂ = 14-24h | | |
| Propranolol (Inderal) | T₁/₂ = 3.5-6h，脂溶性，從低劑量開始往上增加。HTN crisis: IVD > 2min | | |
| Sotalol | T₁/₂ = 12h | | |
| Timolol | T₁/₂ = 4-5h | | |

**適應症：**
① HTN
② 心律不整 (class II)：Propranolol、Esmolol
③ post-MI：timolol、propranolol、metoprolol
④ CHF (可↑存活率)：Metoprolol、bisoprolol、Carvedilol，但要用到 high dose
⑤ 青光眼 (↓IOP)：Timolol、betaxolol
⑥ 甲亢：Propranolol
⑦ 偏頭痛：Propranolol、metoprolol
⑧ tremor：具 β₂ 阻斷者
⑨ 焦慮：propranolol
⑩ infantile hemangioma：propranolol
⑪ 門靜脈高壓：propranolol、nadolol

**選擇藥物方式：**
① 依照有臨床試驗之結果選擇 (見上)
② propranolol 是最古早、適應症最多的藥物
③ β₁ 阻斷：有 asthma、COPD、DM、PAOD
④ α β 阻斷：需較強降壓效果

**S/E：**
① HR↓ (AV block)：HR<50 要停藥
② 支氣管收縮
③ 末梢循環不良
④ 血脂↑ (HDL↓、TG↑、inhibit LPL)
⑤ 血糖↑，DM risk↑
⑥ 疲倦、失眠 (脂溶性過 BBB)
⑦ 性功能障礙

**禁忌症：**
① 急性發作之 asthma、COPD
② DM 且低血糖 (mask 症狀)
③ 末梢循環障礙
④ 2°-3° AV block
⑤ cardiogenic shock
⑥ hypotension (BP < 90mmHg)
⑦ decompensation CHF
⑧ bradycardia (HR < 50 bpm)

### 具 ISA (Intrinsic Sympathomimetic Activity)

ISA = partial β agonist → 降低 HR 的能力較不明顯 → 在 post-MI 沒有幫助，在 angina 或 tachyarrhythmia 效果不好。目前沒有臨床實驗證實這類的藥有特殊療效，研究也顯示沒有 ISA 的 β blocker 在 post-MI 的病人才可減少猝死、總死亡 Rate、反覆心肌梗塞。
