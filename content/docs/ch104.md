# 手術前後藥物給予指引 (Perioperative Medication Guidelines)

[UpToDate (Muluk & Macpherson, 2012)]

## 心血管用藥

| 藥物種類 | 臨床考量 | 短期NPO | 長期NPO |
|----------|----------|---------|---------|
| **β blocker** | Withdrawal會rebound HTN、tachycardia、MI。在有CV risk factor的病人建議術前給予。術前給可降低MI機率，但會增加stroke機率。 | 持續使用到手術當天 | 持續使用到手術當天，術後NPO時用IV propranolol、metoprolol、labetalol。 |
| **α₂ blocker** | Withdrawal會有extreme HTN、MI。 | 持續使用到手術當天。 | 持續使用到手術當天，術後NPO時用SC clonidine或IV methyldopa。 |
| **CCB** | 某些證據顯示可能會增加bleeding。 | 持續使用到手術當天。 | 持續使用到手術當天，術後NPO無替代藥物。 |
| **ACEI/ARB** | 可能造成低血壓。 | 治療HTN則持續使用到手術當天。治療HF且BP不高則早上要停藥。 | 治療HTN則持續使用到手術當天。術後NPO可用IV enalaprilat。 |
| **Diuretics** | 可能造成低血容及低血壓。 | 持續使用到手術前一天，早上停藥。 | 持續使用到手術前一天，早上停藥。術後NPO可用IV form。 |
| **Statins** | 增加myopathy，但具CV保護效果。 | 持續使用到手術當天。 | 持續使用到手術當天。 |
| **Non-statin lipid-lowering agents** | Niacin及fibric acid會造成rhabdomyolysis。Bile acid改變會影響其他藥物吸收。 | 術前停用。 | 術前停用。術後可進食再恢復。 |

## 腸胃科用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **H₂ blocker** | 無已知S/E | 持續使用到手術當天。 | 持續使用到手術當天。術後NPO可用IV form。 |
| **PPIs** | 增加C. difficile感染率 | 持續使用到手術當天。 | 持續使用到手術當天。術後NPO可用IV form PPIs或H₂ blocker。 |

## 肺部用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **Inhaled bronchodilator** | 無已知S/E | 持續使用到手術當天。 | 持續使用到手術當天。 |
| **Theophylline** | 無已知S/E，但therapeutic window很窄。 | 使用到手術前一天，前晚開始停用。 | 使用到手術前一天，前晚開始停用。術後可進食再恢復。 |
| **Leukotriene inhibitor** | 無已知S/E | 持續使用到手術當天。 | 持續使用到手術當天。術後可進食再恢復。 |

## 抗凝血藥物

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **Aspirin / Dipyridamole / Cilostazol** | 增加術中出血，但停用會增加vascular complication。 | CV complication機率高且預期出血不多者可續用。可能會大出血要停用。Aspirin (7-10d), dipyridamole (>2d), cilostazol (2d)。 | 術後可進食再恢復。 |
| **Clopidogrel** | 增加術中出血，但停用會增加stent後的MI。 | Elective OP要被delay。如果是長期服用（與stent無關者），停用5天。 | 術後可進食再恢復。 |
| **Ticagrelor** | | 建議停用5天 | |
| **Prasugrel** | | 建議停用7天 | |
| **Warfarin** | Afib病人用heparin bridge並無好處 (N Engl J Med 2015; 373:823-833)。 | 建議停用直到INR<1.5 | |
| **Dabigatran / apixaban / rivaroxaban** | | 建議停用1-2天 (GFR > 50)，停3-5天 (GFR < 50)。 | 至少停用1天，由低劑量加回使用 |
| **Heparin** | | 停藥4-6小時 | |
| **LMWH** | | 停藥24小時 | |

## 神經科用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **Antiepileptics** | 無已知S/E | 持續使用到手術當天。對穩定控制的病人術後可進食再恢復用藥。IV form可以用phenytoin或phenobarbital取代。 | |

## 精神科用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **Antipsychotics** | 某些藥物會造成QT prolong、hypotension、arrhythmia。 | 建議在高度可能發展成為psychosis的病人持續使用到手術當天。 | 持續使用到手術當天。術後NPO可用IV form。會診精神科。 |
| **BZD** | 突然中斷會導致躁動、HTN、delirium、seizure。 | 持續使用到手術當天。 | 持續使用到手術當天。術後NPO可用IV form。 |
| **Lithium** | 持續使用會造成肌肉鬆弛，且會因抑制腎臟濃縮功能造成hypovolemia及hyperNa。 | 持續使用到手術當天，但要密切監測electrolyte及volume status。 | 可進食再恢復。術後NPO可用valproate或其他antipsychotic替代。 |
| **MAOI** | 持續使用會導致麻醉時期交感反應(高血壓)，及serotonin syndrome。 | 緊急手術要使用MAO-safe anesthesia，非緊急手術考慮停藥2週。 | 可進食再恢復。無IV form替代。 |
| **SRI** | 增加術中出血 | 高風險手術停藥3週。 | 可進食再恢復。無IV form替代。 |
| **TCA** | 增加arrhythmia。突然停藥導致insomnia、nausea、headache、sweating、salivation。 | 對使用高劑量TCA的病人持續使用到手術當天。使用低劑量且可能發生arrhythmia的病人停藥7天。 | 可進食再恢復。無IV form替代。 |
| **Valproic acid** | 無已知S/E | 持續使用到手術當天。 | 持續使用到手術當天。術後NPO可用IV form。 |

## 止痛藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **NSAID** | 增加術中出血，但COX-2比較不會。 | 建議停用3天 (ibuprofen停用1天)，如果必要使用COX-2可不停。 | 建議停用3天 (ibuprofen停用1天)，如果必要使用COX-2可不停。 |
| **Tramadol** | Seizure，藥物交互作用。 | 換成其他種止痛藥 | 換成其他種止痛藥 |
| **Opioids** | 突然停藥導致N/V、失眠、焦慮等。 | 持續使用到手術當天 | 持續使用到手術當天。術後NPO可用IV form。 |

## 風濕免疫科用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **Methotrexate** | 可能導致bone marrow suppression | 持續使用到手術當天，對腎臟不好的人停藥2週。 | 持續使用到手術當天。術後可進食再恢復。 |
| **Sulfasalazine / azathioprine** | 可能導致bone marrow suppression | 停藥1週 | 停藥1週。術後可進食再恢復。 |
| **Leflunomide** | 可能導致bone marrow suppression | 停藥2週 | 停藥2週。術後可進食再恢復。 |
| **Hydroxychloroquine** | 副作用機會很低 | 持續使用到手術當天 | 持續使用到手術當天。術後可進食再恢復。 |
| **Biologic agent (etanercept, infliximab, anakinra, rituximab, adalimumab)** | 使用會增加感染危險 | 停藥1-2週，術後1-2週再回復使用。 | 停藥1-2週，術後1-2週再回復使用。 |
| **Colchicine / allopurinol / probenecid** | 突然停藥可能造成gout attack。另probenecid和一些術前用藥有交互作用。 | 持續使用到手術前天，當天早上停藥。 | 持續使用到手術前天，當天早上停藥。術後可進食再恢復。可用關節內注射steroid控制gout attack。 |

## 內分泌用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **OCPs / HRT / SERM** | 停用增加thromboembolism。另外停用OCP可能會造成懷孕。 | 中低風險手術持續使用到手術當天；高風險手術停藥4-6週。停用OCP要在術前驗孕。若SERM是用來治療乳癌，需會診。 | 中低風險手術持續使用到手術當天；高風險手術停藥4-6週，可進食後便能恢復使用。停用OCP要在術前驗孕。若SERM是用來治療乳癌，需會診。 |

## 糖尿病用藥

| 藥物 | 臨床考量 | 短期NPO | 長期NPO |
|------|----------|---------|---------|
| **T2DM 用 OHA** | 吃OHA到術前一天，當天早上不吃，如果高血糖用sliding scale。術後恢復飲食即可吃回去，但注意如果病人有renal hypoperfusion則metformin要先停。 | SU造成術中低血糖；metformin造成renal hypoperfusion、lactic acidosis、hypoxia；TZD造成fluid retention；DPP-IV或GLP-1 analog會改變GI motility | |
| **T1DM 或 T2DM 用 insulin** | 打SC到術前一天，停用手術當天的短效，前一晚的中長效不用降低劑量，IV用D5W run 75-125ml/hr。術後恢復施打，並且要縮含糖fluid (5-10g/h)。 | 若病人是QD打insulin → 用中效或長效insulin給1/2-2/3 TDD。若病人是BID打 → 用中效或長效insulin給1/3-1/2的morning dose | |
| **長時間手術** | 手術當天早上給IV insulin。術後持續給予IV RI，直到恢復飲食才改回SC。 | GIK solution: D5W 500ml + 5U insulin + 10 mEq KCl run 100ml/h, check K Q6H. | |
