# 風濕免疫用藥

| 藥物類別 | 子分類 | 作用機制 | 副作用/注意事項 |
|---------|--------|---------|----------------|
| **NSAID** | | 改善症狀，但無法避免或減緩關節軟骨破壞，急性期用。 | |
| **小劑量類固醇** | | 急性期用或DMARDs尚未產生療效時用，無法避免RA progression。如果要長期使用，建議每天劑量 < 7.5mg/d prednisone。 | |

## DMARDs (Disease Modified Anti-rheumatic Drugs)

6週到6個月才見效。

### 傳統DMARDs

| 藥物 | Onset | 劑量 | 作用機制 | S/E |
|------|-------|------|-----------|-----|
| **Gold Na⁺ thiomalate (IM) / Auranofin (PO)** | | | 抑制吞噬作用及lysosome酵素活性 | ① GI症狀、皮膚癢、nephrotic syndrome (Dimercaprol解毒)。② 目前不建議使用，因為毒性以及效果不佳。 |
| **Hydroxychloroquine (Plaquenil) (HCQ)** | | | ① 藉由使lysosome pH提高及增加內膜穩定，抑制MHC class II細胞（即APC）中的processing和loading，進而降低T cell activation。② 適用：dermatitis、alopecia、synovitis of SLE and RA、各種AIR都可以用（除了PsA，因會induce發作），也可用來治療瘧疾。 | ① GI症狀、皮膚癢、頭痛、視覺障礙 (dose-related retinopathy)、maculopapular rash (pigmentation)。② 禁忌症：porphyria, G6PD, 肝腎不好。③ 懷孕可用，可降低steroid dose。 |
| **Sulfasalazine** | 4週 | 2-3 g/d | ① 代謝成sulfapyridine，抑制T細胞和B細胞的功能，並減少IgA和IgM等rheumatoid factor的產生。② 適用：synovitis of RA、sero-negative arthritis、IBD。 | ① GI症狀、皮疹、leukopenia、methemoglobinemia、acute fibrotic alveolitis with eosinophilia。② 禁忌症：G6PD、sulfa allergy，懷孕可用。 |
| **D-Penicillamine (Metalcaptase)** | | | 機轉不明 (原為螯合劑)，具anti-fibrosis。適用：systemic scleroderma。 | GI症狀、皮膚炎、腎炎、thrombocytopenia。 |
| **Leflunomide (Arava) (Arheuma)** | | 10-20mg QD | ① 在腸道和血漿中轉變成為teriflunomide，抑制dihydro-orotate dehydrogenase，導致pyrimidine無法合成，細胞停留在G1 phase。② 適用：RA。 | ① GI症狀 (腹瀉)、↑ AST、rash、alopecia、體重增加。② cholestyramine 8mg TID x 11d解毒 (加速藥物排除)。③ 禁忌症：肝不好、在吃rifampin、懷孕。 |
| **Methotrexate (MTX)** | | | ① 低劑量抑制thymidylate synthetase及AICAR transformylase，高劑量抑制dihydrofolate reductase，可直接導致發炎細胞apoptosis。② 適用：synovitis、myositis、leukopenia of Felty syndrome、AS、SLE。 | ① BM抑制、pneumonitis、hepatotoxicity、噁心、mucositis、nephrotoxicity。② DMARDs見效最快者。在DMARD使用低劑量 (15-35mg/week)，在cancer使用高劑量。③ 可以在每週吃完MTX後給leucovorin，或每天吃folic acid降低毒性，但也可能降低藥效。④ 禁忌症：懷孕。 |
| **MMF** | | | 適用：lupus nephritis、vasculitis、Wegener's granulomatosis。 | 其他詳見「免疫抑制劑」。 |
| **Azathioprine** | | | ① 在體內代謝成6-MP，為purine analog → de novo purine synthesis ↓。② 適用：PsA、RA、polymyositis、SLE、Behcet's disease。 | BM suppression (較常見leukopenia)、N/V、發燒、紅疹、肝毒性。 |
| **Cyclosporine** | | | ① 與cyclophilin結合成複合體，直接抑制calcineurin，降低IL-1及IL-2。② 適用：SLE、polymyositis and dermatomyositis、Wegener's granulomatosis、juvenile chronic arthritis。 | 肝毒性、腎毒性、HTN、高血鉀。不具BM毒性。 |

### Biological DMARDs

| 藥物 | 作用機制 | 共同S/E | 禁忌症 |
|------|---------|---------|--------|
| **Adalimumab (Humira)** 40mg QW | ① 為TNFα inhibitor，結合soluble、細胞膜上的TNFα，抑制macrophage及T cell功能。② 共同適應症：RA、AS、PsA、JRA、Crohn's disease (除Etanercept、Golimumab)、plaque psoriasis。 | ① 共同S/E：細菌感染、macrophage-dependent infection (TB、其他伺機性感染)。 | 共同禁忌症：TB、zoaster。 |
| **Etanercept (Enbrel)** 25mg BIW 或 50mg QW | 結構為TNF p75 R + IgG1的Fc，也會抑制lymphotoxin-α。 | | |
| **Infliximab (Remicade)** 3-5mg/kg Q8W | | 額外S/E：demyelinating syndromes、肝炎、HBV flare up、leukemia、會刺激anti-chimeric antibodies產生降低藥效。 | 額外禁忌症：multiple sclerosis。 |
| **Golimumab (Simponi)** Q month | | | 額外禁忌症：CHF NYHA Fc III-IV。 |
| **Abatacept (Orencia)** | ① 似CTLA4，結合到CD80/CD86，防止T cell activation。② 適用：中重度RA，尤其是使用DMARD無效者。 | S/E：增加感染風險 (上呼吸道)、過敏。 | |
| **Rituximab (Mabthera)** | ① Anti-CD20，同時抑制細胞及體液免疫，減少B細胞。② 適用：與MTX併用治active RA (對anti-TNF無效者)。 | ① S/E：紅疹、增加感染風險，不會活化TB或是增加癌症的風險。② 給藥前30分鐘給100mg methylprednisolone降低過敏。 | |
| **Anakinra (Kineret)** | 結構似IL-1，為IL-1 R antagonist。 | | 禁忌症：惡性腫瘤、neutropenia、Ccr < 30、active TB。 |
| **Tocilizumab (Actemra)** | Bind IL-6 R，抑制T cell activation。 | | 禁忌症：acute infection、TB。 |

### 其他免疫抑制劑

| 藥物 | 作用機制 | S/E |
|------|---------|-----|
| **Cyclophosphamide (Endoxan)** | ① 代謝成phosphoramide mustard會結合到DNA上阻斷細胞複製，可降低T cell及B cell功能達30-40%。② 適用：SLE、vasculitis、Wegener's granulomatosis。 | 其他詳見「化療藥」。IV pulse therapy：10mg/kg Endoxan，2週後要check WBC。 |
