# ■ 減肥藥

| 類別 | 藥物 | 說明 | S/E |
|------|------|------|------|
| 抑制脂肪的吸收 | Orlistat (羅氏鮮) (Xenical) | 在小腸抑制lipase，可↓ 30%脂肪吸收。 | 120 or 80mg TID S/E：GI distress、↓ 脂溶性維生素吸收、肝毒性(具爭議性)。 |

| | PPA (禁藥) | 安非他命類的交感神經興奮性 | |

| **Phentermine** | 15mg QD | 15-37.5mg QD | 37.5mg/day | QD | PO |

## 減肥藥適應症快速參照

| 藥物 | 主要適應症 |
|------|-----------|
| **Orlistat** | 肥胖、BMI>=30 或 BMI>=27 合併肥胖相關疾病 |
| **Phentermine** | 短期減重（<=12週）|
| **Liraglutide** | 肥胖、減重 |
| **Lorcaserin** | 肥胖（已下架）|
