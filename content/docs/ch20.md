# 心臟衰竭用藥 (Heart Failure Medications)

## 人體代償模式

- ↑RAAS
- ↑Sympathetic tone
- ↑ANP (心房)
- ↑BNP (心室)
- ↑CNP (CNS)
- ↓Endothelin

## 血管擴張劑

### 機轉

| 作用 | 效果 |
|------|------|
| 擴張 artery | 造成 SVR↓ → afterload↓ → SV↑、IVEDP↑、CO↑ |
| 擴張 vein | 造成 preload↓ → Pulm. congestion 及 systemic venous pooling（不改變 CO）|

### 藥物

| 藥物 | 作用 | 臨床應用 |
|------|------|----------|
| **Nitrate**（擴張 V） | V>A | 急性 coronary syndrome |
| **Hydralazine**（擴張 A） | A>V | +Nitrate 可增加存活率 |
| **NTG** (Millisrol 5mg/10ml) | | |
| **Nitroprusside** | A=V | 丁t1/2=1-3min，代謝成 thiocyanate 導致 S/E (nausea、AMS、abd pain、seizure、methemoglobinemia) |
| **Nesiritide** | A=V | Recombinant BNP |
| **Enalaprilat** | | 不適用於急性心衰竭 |

## 利尿劑

| 藥物 | 適應症 |
|------|--------|
| **Loop diuretics** | 急性肺水腫＋嚴重 CHF（furosemide 優先）|
| **Thiazide** | Mild CHF |
| **Spironolactone** | 阻斷 RAAS 可以增加存活率 |

## 強心劑 (Cardiac Glycosides)

### Digoxin (Digitalis)

#### 機轉

| 作用 | 效果 |
|------|------|
| ①抑制 Na/K ATPase | → 細胞內 Na↑ → Na/Ca exchange↓ → Na↓, Ca↑ → 易去極化 (arrhythmia) |
| ②興奮迷走神經 | → HR↓ (SA/AV node) |
| ③抑制 NAT/K ATPase | → SV↑、HR↓（減少耗氧）：減輕 CHF |
| ④ AV node | → PR interval↑：治心率不整 |

#### 適應症

- 改善 HF 症狀最明顯
- 不影響存活率

#### S/E、中毒症狀

1. HR↓（<60bpm 須停藥）
2. 心室心率不整（常見 PAT w/ varying AVB、bidirectional VT）
3. GI upset、頭痛、yellow vision（視覺障礙）
4. Therapeutic window 小（0.8-2ng/ml），易中毒
5. 易有 drug reaction

#### 禁忌症

- Hypertrophic cardiomyopathy

#### 解毒

| 方法 | 說明 |
|------|------|
| 緩慢 ↑K+ 以解毒 | 禁鈣鹽 |
| 抗心率不整藥 | Lidocaine、Phenytoin、Procainamide |
| 禁用 Quinidine | 因會降低 Digoxin 在腎臟的排泄 |
| 毛地黃抗體 | |

### Digitoxin

- 脂溶性高、長效、口服吸收最佳、肝代謝、膽汁排泄
- 臨床不用

| 藥物 | 機轉 | 作用 |
|------|------|------|
| **Dobutamine** | β1 agonist | ↑心肌 CAMP (SV↑, HR↑)（但↑死亡率）|
| **Dopamine** | | |
| **Amrinone** | PDE3 抑制劑 | ↑心肌 CAMP (SV↑, HR↑)（但↑死亡率）|

- 低血壓

## 慢性心衰竭治療

### 核心藥物（Block neuroendocrine）

| 藥物 | 作用 | 效果 |
|------|------|------|
| ACEI/ARB | Block RAAS | ↑存活率 |
| Aldosterone antagonist | Block RAAS | ↑存活率 |
| β-blocker | Block sympathetic tone | ↑存活率 |

> 單用效果：β-blocker > AA > ACEI > ARB

## HF 用藥流程 (ACC/AHA Heart Failure Guidelines, 2009)

1. 限鹽、限水、給利尿劑

2. 針對所有病人使用 ACEI、β-blocker（僅 bisoprolol, carvedilol, metoprolol SR），除非有禁忌症。ARB 僅適用在不能適應 ACEI 的病人。

3. Aldosterone antagonist 僅在部分病人建議使用：moderate to severe HF + reduced LVEF + 病人可以配合監測腎功能及鉀離子。Creatinine 在男性要 <2.5mg/dl，女性要 <2.0mg/dl，且鉀離子要 <5mEq/L。(Class I)

4. 如果病人是 African-American，或者在上述藥物之後仍有 moderate to severe HF 的症狀，可以使用 hydralazine + nitrate。(Class I)

5. 停用可能造成 HF 加劇的藥，如 NSAID、antiarrhythmic drug、CCB。(Class I)

6. 運動訓練、限制活動、減輕體重、控制高血壓。(Class II)

7. Digitalis 可以在病人有 HF 症狀時使用以降低住院時間，但不建議長期使用。(Class IIa)

8. 若病人為 AFib 合併 HF，則建議使用 β-blocker 或 amiodarone 控制心律 (Class I)，使用 digitalis 則是 Class IIa。

9. 針對末期 HF 病人 Class I 的治療：heart transplant、討論 DNR、注意 fluid status、會診相關專家。

10. **結論**：Diuretics → ACEI (ARB) → β-blocker → aldosterone antagonist → digitalis → hydralazine + nitrate

## 重要臨床試驗

### ATLAS Trial

高劑量（32.5-35mg/d）vs 低劑量（2.5-5mg/d）lisinopril：
- 高劑量可↓8% all-cause mortality (P=0.128)
- ↓12% combined risk of death or hospitalization for CHF (P=0.002)
- ↓24% hospitalization of heart failure (P=0.002)

### VALIANT Trial

比較 post-MI 後合併 heart failure 或 LVEF < 35% 的病人：
- Valsartan、captopril、或兩者合併
- 在 all cause death 或 death of CV event 均顯示三組效果相當
- 兩者併用會增加副作用
