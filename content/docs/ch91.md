# 維生素

（僅提供臨床使用之 indication，不提供保健食品的功能。）

| Vitamin | Drug Name | Indication |
|---------|-----------|------------|
| **Thiamine (B₁)** | Thiamine | Wernicke's encephalopathy, thiamine deficiency, shoshin beriberi syn. |
| **B₆** | Pyridoxine | 孕婦止吐，預防結核藥 INH 造成的 Neuropathy（參見 TB 藥中 VitB₆ 的適應症）。禁止與 L-dopa 併用 |
| **Folic acid (B₉)** | Folic Acid (Folacin) | 用於 Megaloblastic anemia。與 MTX 併用可降低其毒性（Folic Acid 為 MTX 解毒劑）。與 5-FU 併用可加強其殺腫瘤效果 |
| **B₁₂** | Mecobalamin (Mecomin、Methycobal), Cyanocobalamin | 用於 Peripheral neuralgia |
| **B complex** | Kentamin (B₁ 50mg + B₆ 50mg + B₁₂ 0.5mg) | 除了維他命 B 缺乏的補充外，有時用於 sudden hearing loss |
| | Vitalex (B₁ 10mg + B₂ 10mg + B₆ 3mg) | |
| | Combeplex (B₁ 100mg + B₂ 5mg + B₆ 5mg) | |
| **C** | Yu sheng C 200mg/Tab; Vitacicol 100mg/Amp | 長期 NPO 者 |
| **D₃** | — | 用於 Chronic renal failure、osteoporosis、hypoparathyroidism。單純 Vit D deficiency：補 ergocalciferol 400-1000 U/day。Calcitriol 作用較快，給 0.5-2 μg/day，要監測磷 |
| **E** | Vitamin E (α-tocopherol) | 對於 NASH 病人使用 800 U/day 可以改善肝功能，但會增加 mortality 以及 prostate cancer 發生率 |
| **K₁** | Phytonadione (Katimin) | 用於 Warfarin 中毒 |
| **Vit. Complex** | Infuvita、Octa-Vita Drop | |

|---------|---------|---------|------|------|

| Pyridoxine (B₆) | 25-50mg PO QD | 25mg PO BID-TID | PO | 預防INH神經病變 |
| Folic Acid (B₉) | 5-15mg PO QD | 1-5mg PO QD (與MTX併用) | PO | Megaloblastic anemia |
