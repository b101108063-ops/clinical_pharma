# CH80 軟便劑 (Laxatives)

**以下流程為針對 chronic functional constipation 之處置建議**

## 非藥物治療

| 治療方式 | 說明 |
|----------|------|
| 生活型態及飲食調整 | 定時排便，建議在走路後或飯後兩小時內 |
| 高纖飲食 | 建議 20-25g/day，S/E 是 bloating、flatulence |

## Bulk-forming

| 藥物 | Dose | Onset | 備註 |
|------|------|-------|------|
| Psyllium (Metamucil) | 1茶匙 (3.5g fiber) QD-TID | 12-72h | ① 最安全: 服用後要喝大量水 (~1000ml) 以增加容積<br>② ↑ 排便頻次，並使大便軟化，不過 evidence 不強 |
| 增加大便的量以刺激腸道 | 1茶匙 (2g fiber) 或 4 cap (2g fiber) TID | 12-72h | |
| Polycarbophil | 2-4 #/d (500mg fiber per #) | 24-48h | |
| Wheat dextrin | 1-3 # (1g/#) TID | 24-48h | |
| Normacol (Sterculia 62% + Frangula 8%) 1# QD-BID | | | |

## Hyperosmotic

非吸收的鹽、醣類在大腸內形成高滲透壓 → ↑H₂O retention 而增加腸道內容積

| 藥物 | Dose | Onset | 備註 |
|------|------|-------|------|
| Polyethylene glycol = PEG (Miralax) | 8.5-34g in 240ml liquid | 1-4d | ① S/E: 脹氣、絞痛、衰弱病人會 electrolyte imbalance + dehydration<br>② 禁忌症: 腎不好者禁用含 Mg 的<br>③ 效果 PEG > lactulose = sorbitol<br>④ Lactulose 在大腸經細菌代謝成 fatty acid 酸化腸道，↓NH₃，可治療肝腦病變 |
| Lactulose < 2y/o 常用 | 10-20g (15-30ml) QD-BID<br>肝腦病變 30-50ml TID-QID，目標拉 2-4 次/d | 24-48h | |
| Sorbitol | 30g QD | 24-48h | |
| MgSO₄ | 5-10g in 240ml QD | 0.5-3h | |
| Mg citrate | 11.6g QD | 0.5-3h | |
| MgO (250 mg/tab) | > 1g/d | 0.5-3h | |

## Stimulants

刺激神經增加腸蠕動。**腸阻塞禁用**

| 類別 | 藥物 | 劑量 | Onset | 備註 |
|------|------|------|-------|------|
| 小腸 | Castor oil | 15-60ml QD | | [蓖麻油 (Ricinolic acid)] 造成快速排空 |
| 大腸 合成 | Bisacodyl (Dulcolax) | 10-30mg QD | 6-10h | 睡前口服或白天塞劑使用，不可磨粉 |
| | Docusate | Docusate sodium 100mg BID-QID<br>Docusate calcium 240mg QD | 24-72h | 可降低表面張力，促進軟便及刺激腸道，並增加腸道內分泌 |
