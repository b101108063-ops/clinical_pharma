## 放射碘

¹³¹I

| | |
|---|---|
| ① | 自吃入至破壞腺體須數週。 |
| ② | 服用於孕婦(需通過胎盤)-破壞胎兒甲狀腺，缺碘盛行率，breast-feeding。 |
| ③ | If 果tumor發生NIS (sodium iodide symporter)變異則無效。 |

適應症：Grave's disease (10 mCi)、toxic adenoma=Pullmer's dz (15 mCi)、治療無效dose x 15。固體r-lobute及roducte(利賓氏賽的ryhroid，所以打高劑量安全)、thyroid cancer (30 mCi)，如可住院用75-200mCi，提高成功率約85%。

機轉：直接破壞甲狀腺體(¹³¹I用於診斷)。

注意：使用前要先做3dQCMZMNZ，PTH，life-long hypothyroidism、絕育thyrotoxic crisis。

## β阻斷劑

Propranolol

其它 β 膽鹼或 M乙之症狀

| | |
|---|---|
| ① | 10-40 mg QID (控制 HR<100)<br>②改善心悸、手顫、焦慮等症狀。 |

適應症：thyroid storm。

機轉：①抑制周邊T₄→T₃(去碘化)：β阻斷劑中唯propranol有此作用。<br>②抑制交感神經，申元肺心肌細胞上的 β-receptor增加。

## 類固醇

Hydrocortisone

在thyroid crisis有relative adrenal insufficiency

適應症：subacute thyroiditis (virus infection)、thyroid crisis。

機轉：抑制周邊T₄→T₃(去碘化)。

Ticunicide使用：易於孕婦1-5-3y行前考慮停藥。
停藥後條件：使用後特殊案例藥物成份、TSH-RAb (代表relapse機會低)、+normal TSH/T4：停藥後要追蹤甲狀腺功能。
