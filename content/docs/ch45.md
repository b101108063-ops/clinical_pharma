# 抗生素

## 常用菌種代號

E. coli (Ec), K. pneumoniae (K), H. influenzae (H), Proteus (P), Listeria (L), Neisseria (N), Salmonella (Sa), Shigella (Sh), Enterobacter (E), Moraxella (M), Pseudomonas aeruginosa (PsA).

Atypical: mycoplasma, chlamydia, legionella, rickettsiae; Spirochete: Treponema pallidum, Leptospira, Borrelia burgdorferi.

## 抑制細胞壁合成

特點：S/E小、孕婦可用。對快速生長之細菌較有效。

### β-lactam

- 易有過敏交叉反應
- 會產生β-lactamase：S. aureus, N. gonorrhea, P. aeruginosa
- Postantibiotic effect (PAE)：對G(+)有PAE，對G(-)無PAE
- Synergism：penicillin + AG (↑GPC)
- Antagonism：penicillin + neomycin/tetracycline

**機轉：** 抑制細胞壁cross-link。因似Acyl-D-alanyl-D-alanine，與PBPs (Penicillin-binding protein)結合 → 阻斷細菌細胞壁peptidoglycan的crosslink。

**S/E：** 過敏休克 (預先作Penicillin Skin test (PPV 50%, NPV 97-99%))、GI distress、BM抑制。

**注意：** ① 效短 (+Probeneciud增加小管分泌)。② 對Penicillin過敏者，用Erythromycin、Lincomycin、Clindamycin替代。

### Penicillin

越往下GNB越強。

**重要菌種：** Natural: spirochetes [(Treponema pallidum (梅毒)、Leptospira、Borrelia burgdorferi)]、anaerobes (actinomyces、clostridium)、Neisseria meningitidis。

**No MRSA, PRSP, ampicillin-resistant enterococci.**

| 分類 | 藥物 | 特色 |
|------|------|------|
| **天然 (nature)** | Penicillin G (IV) | Acid-labile、短效 |
| | Penicillin V (PO) | Acid-stable |
| | Benzathine | IM、長效、syphilis |
| **耐酸+酶 (Penicillinase-resistant penicillins)** | Methicillin | 腎毒、注射 (臨床不用) |
| | Nafcillin (IV) | |
| | Oxacillin (IV) | ① PO的耐酸&酶，但抗菌較弱 |
| | Cloxacillin (PO) | 肝代謝 (Penicillin中僅此類)，腎不好不用調dose |
| | Dicloxacillin (PO) | S/E：hepatitis |
| **廣效 (Broad spectrum)** | Aminopenicillin - Ampicillin | ① PO吸收40%。② +Sulbactam = Unasyn (IV only) |
| | Amoxicillin | ① PO吸收80-90%。② +Clavulanate = Augmentin (PO, IV) |
| **廣效 (Extended spectrum)** | Carboxypenicillin - Carbenicillin | 臨床不用 |
| | Ticarcillin | +clavulanate = Timentin |
| | Ureidopenicillin - Piperacillin | +tazobactam = Tazocin (比Timentin強) |

**β-lactamase inhibitor：**
- ① sulbactam：最弱、對AB菌有效。
- ② clavulanate：較易有GI upset。
- ③ tazobactam：最強。

### Cephalosporin

對penicillinases比較不sensitive。

**特點：** 第一代到第三代G(+)變弱G(-)變強，第四代都很強外加抗PsA。Cephamycin對厭氧和ESBL有效。No Enterococcus, Listeria, MRSA (第五代前)。No anaerobes (除cephamycin類)。

| 代數 | 藥物 | 特色 |
|------|------|------|
| **第一代** 不通過BBB | Cephalexin (口服), Cefazolin (注射), Cephradine | ① Cefazolin (T₁/₂ = 1.7h) 術前預防感染。② 對Staph./Strep.的效果比penicillin弱。 |
| **第二代** 不通過BBB | Cefuroxime (均有) | 橫膈上感染。對G(+)、anaerobes最強，不含NMTT。 |
| | Cefaclor (口服), Cefoxitin, Cefmetazole, Cefotetan (Cephamycins類) | |
| **第三代** 除CPZ外，均通過BBB | Ceftazidime (Fortum) | 殺綠膿桿菌佳，其他GNB、GPC差。CPZ含NMTT。 |
| | Cefotaxime (Claforan) | G(+)最強。殺綠膿桿菌差，其他GNB、GPC佳。 |
| | Ceftriaxone (Rocephin) | G(+)次強。Rocephin和albumin結合，故newborn禁用 (↑bilirubin → kernicterus)。 |
| | Ceftizoxime (Epocelin), Ceftibuten (口服) | |
| **第四代** | Flomoxef (Flumarin), Latamoxef (Cephamycins類) | 不含NMTT的cephamycin |
| | Cefepime, Cefpirome | 不被β-lactamase破壞，cefepime對PsA較有效，cefpirome對G(+)較有效。 |
| **第五代** | Ceftaroline (Teflaro) | 第四代範圍＋MRSA、enterococcus。要IVD 1小時。 |

**S/E：** ① 過敏反應較小。② 血栓靜脈炎。③ 輕腎毒。④ 輕BM抑制。

**NMTT支鏈：** cephamycin + CPZ。① 抑制prothrombin合成→補Vit K 1amp BIW。② Disulfiram-like reaction造成alcohol intolerance→避免喝酒。

### Carbapenem

超廣效 [G(+)、(-)、anaerobes]。Tienam僅四種殺不死 (見最右欄)。

| 藥物 | 特色 |
|------|------|
| **Imipenem + Cilastatin (=Tienam)** | +Cilastatin可↑藥效及↓腎毒 (藉由抑制DHP-I)。對AB、G(+)較有效，但seizure risk較高，故不用在meningitis。 |
| **Ertapenem** | 對AB菌、腸球菌及綠膿桿菌無效，故主用於社區感染。 |
| **Meropenem (Mepem)** | ① 對AB外的G(-)較有效，在腎小管穩定 (較不傷腎)。② 適用CNS infxn，對Burkholderia有效。S/E: 易seizure。 |
| **Doripenem** | 在膽道濃度較其他carbapenem高，在lung無適應症。 |

### Glycopeptide

G(+)、MRSA、anaerobes。

| 藥物 | 特色 |
|------|------|
| **Vancomycin** | 15%過BBB、lung & tissue穿透力較差。治療：① ORSA (MRSA) 引起的感染。② 預防心內膜炎。③ 對β-lactam過敏者的G(+)感染。④ Metronidazole無效的偽膜性大腸炎 (PO優先)。機轉：抑制細胞壁polymerization。三環glycopeptide抗生素。多數G(+)殺菌有效，但結構大而無法進入G(-)。S/E：① 快速滴注histamine release導致Red man syndrome → 故vanco給藥需IVD > 2h，用antihistamine治療。② 腎毒性、耳毒性 (尤其合用Aminoglycoside, amphotericin B)。③ Neutropenia。④ Hypersensitivity。 |
| **Teicoplanin** | Half-life↑、腎毒性↓、不過BBB lung和bone穿透力較好。 |
| **Telavancin** | 由Vanco來，機轉類似，但多了破壞cell membrane (藉由depolarization)。 |

### 其他細胞壁抑制劑

| 藥物 | 特色 |
|------|------|
| **Bacitracin** | G(+)。腎毒性大→外用 (+Neomycin)。 |
| **Fosfomycin** | G(+)、G(-)、含MRSA、ESBL。No anaerobes、AB、P. aeruginosa。+vanco可有synergistic effect殺MRSA。① 對組織penetration很好，但FDA只核准用在女性UTI。② 代謝：腎。③ UTI: 1g q8, systemic: 50mg/kg (2-4) q8。④ 可考慮在MRSA、ESBL使用。 |

## 抑制蛋白質合成

特點：孕婦不適用。抗菌效力不受細菌數影響，對不再生長細菌也有效。

- 50S: erythromycin、chloramphenicol、clindamycin、streptogramin、linezolid.
- 30S: aminoglycoside、tetracycline、glycylcycline.

### Aminoglycosides

① 多數G(-) 含PsA。② 部分G(+)：S. aureus、CoNS、Strep. viridans、Enterococci (PCN類合用)。③ Mycobacteria。④ No anaerobes。

| 藥物 | 特性 |
|------|------|
| **Streptomycin** | ① TB一線藥。② 與Penicillin協同治心內膜炎。③ 耳毒 (前庭神經受損) > 腎毒 |
| **Gentamicin** | 腎毒大 |
| **Tobramycin** | PsA最強，腎毒大 |
| **Amikacin (Amikin)** | ① 半合成、不易產生抗藥性。② TB二線藥。③ Gentamicin有抗藥時用之 |
| **Isepamicin (Exacin)** | 肺穿透力好 |

**作用：** ① 抑制蛋白質抗生素中唯一殺菌。② 常利用β-lactam抗生素助其穿過細胞膜而合用。③ 在缺氧、酸性的環境下作用不佳 → 厭氧菌、膿疡無效。④ 水溶性、原型腎臟排出 (治UTI佳)。⑤ Post-antibiotics effect。

**機轉：** 作用於30S核醣體 (Incorrect reading of mRNA)。

**S/E：** ① 耳毒性、前庭毒性。② 腎毒性 (if >5d, elder, CKD)。③ 神經肌肉阻斷：臨床若與骨骼肌鬆弛劑合用於使用呼吸器的病人，不易Weaning。用Ca gluconate或neostigmine回復。

### Tetracyclines

廣效G(+)(-)：Chlamydia, Mycoplasma, rickettsiae, spirochetes, Vibrio, Aeromonas。

| 藥物 | 特色 |
|------|------|
| **Tetracycline** | ① 常見抗藥性。② 食物易影響吸收。S/E：① 棕色牙齒 (<8y/o或孕婦禁用)。② 光敏感性。③ Superinfection。④ BUN上升。⑤ Pseudotumor cerebri。 |
| **Minocycline IV** | ① 受食物影響少，不須空腹。② 治Acne佳。③ minocycline做pleurodesis。 |
| **Doxycycline PO** | doxycycline預防malaria。 |

**機轉：** 作用於30S核醣體 (阻斷tRNA binding)。

### Glycylcyclines

| 藥物 | 特色 |
|------|------|
| **Tigecycline (Tygacil)** | ① 肝不好要調整劑量。② 對IAI、軟組織感染很有效。③ ↑all-cause mortality (目前具爭議性)。其實是minocycline改造過來，故機轉、S/E均相同。老虎不能玩3P：Pseudomonas、Proteus、Providencia無效。老虎怕水：bacteremia、UTI、meningitis、IE效果不好。 |

### Macrolides (Erythromycins)

廣效：許多G(+)、部分GNB、atypical、Vibrio、Corynebacterium diphtheriae (白喉)、Campylobacter jejuni、Ureaplasma、Bordetella pertussis (百日咳)。

| 藥物 | 特色 |
|------|------|
| **Erythromycin** | Most cost-effect，造成QT prolong。對H. influenzae無效。作用：① Legionella、Mycoplasma首選。② 可做Penicillin過敏時的替代品。③ G(+)在台灣已無杀菌效果。藥物交互作用 (Azithromycin無)：① ↓p450：Terfenadine、Astemizole、Cisapride合用造成QT延長的心律不整。② 改變腸道菌種：↑Digoxin作用。S/E：① 腸胃症狀 (↑GI蠕動)。② 過敏。③ 膽汁鬱積性肝炎。④ QT prolong。 |
| **Clarithromycin (Klaricid)** | 對NTM、H. pylori、Toxoplasma有杀菌力。 |
| **Azithromycin (Zithromax)** | ① 最大Compliance。② 最小腸胃S/E。③ 最小藥物交互作用 (不↓p450)。④ 最方便 (因半衰期長可QD)。⑤ 組織濃度 > 血中濃度。 |

**機轉：** 作用50S核醣體 (抑制translocation)。代謝：肝。

### Lincosamide

| 藥物 | 特色 |
|------|------|
| **Lincomycin** | 口服吸收差；可穿過BBB。作用：① 對G(+)抗菌似Erythromycin，且對大部分厭氧菌均有效。② 腹腔/骨盆腔等部位感染厭氧菌的重要抗生素。③ 對Penicillin過敏或抗藥時的替代品。S/E：① 偽膜性大腸炎 (diarrhea)。② Thrombocytopenia、Leukopenia、Granulocytopenia。 |
| **Clindamycin** | 口服吸收佳、常代替erythromycin。肝代謝。Anaerobes (橫膈膜以上)：G(+)的Anaerobes為主，對Bacteroides效果不可信。 |

### 其他蛋白質合成抑制劑

| 藥物 | 特色 |
|------|------|
| **Streptogramin - Quinupristin/dalfopristin (Synercid)** | Quinupristin似pristinamycin IIA，Dalfopristin似pristinamycin IA。兩者以3/7混和，具杀菌效果。針對MRSA、VRE。 |
| **Chloramphenicol** | 作用：① 廣效：G(+)(-)厭氧菌。② 抑菌：S. aureus、腸內菌科。③ 殺菌：H. influenza、S. pneumoniae、Neisseria meningitidis。④ 立克次體：<8y/o不可用Tetracycline時替代。S/E：① Gray baby syndrome (infant缺乏UPD-glucuronyl transferase)。② Blood dyscrasia。③ G6PD缺乏者禁用。④ Aplastic anemia。機轉：作用於50S核醣體之23S次單元 (抑制Peptidyl transferase)。 |
| **Oxazolidinones - Linezolid (Zyvox), Tedizolid** | G(+)含VRE。CSF 70% penetration。Lung穿透力好 (勝過daptomycin)。肝代謝。具部分MAOI。PO和IV效果相同。S/E：myelosuppression (補充Vit B6)、lactic acidosis、GI distress。 |
| **Fusidic acid (Fucidin)** | 只對G(+)有效。抑制蛋白質elongation factor。 |

## 抑制細菌新陳代謝 (葉酸)

在D5W，因在N/S會沉澱。孕婦不適用。

### Sulfonamide

① 抑制PABA轉成FH2所需的Dihydropteroate synthetase。② 立克次體可用此做營養來源。③ 第一個使用在人類的抗微生物藥。④ 在人體之主要生物轉變代謝作用為Acetylation。

**Cotrimoxazole (Baktar)** = Sulfamethoxazole (SMX) 400mg + TMP 80mg (協同變成杀菌類+降低抗藥性)。

**治療：** ① 泌尿道感染、前列腺炎 2 tab PO Q12H。② Infectious diarrhea (Shigella、Salmonella)：1 amp IV q12。③ PJP：15-20mg/kg/d TMP分3~4次。④ Bacteremia：2 amp IV q12。

### Trimethoprim (TMP)

抑制FH2轉成FH4所需的Dihydrofolate reductase (MTX亦作用於此酵素)。

**S/E：** ① 腸胃症狀 (N/V)、cholestatic jaundice。② 易allergy (先desensitization非換藥)。③ 結晶尿導致AKI (多喝水預防)。④ G6PD缺乏者禁。⑤ BM suppression (pancytopenia)。⑥ Hallucination、seizure：IV易產生。⑦ HyperK hypo Na、Type IV RTA。

## 抑制核酸

孕婦不適用。

### Quinolones

① 口服佳。② 組織穿透佳。③ 廣效。④ Acquire resistance easily。

| 分類 | 藥物 | 特色 |
|------|------|------|
| **第一代** | Nalidixic acid | PEcK，易產生抗藥性 (不含氟基) |
| | Pipemidic acid | PEcK + PsA，常用在UTI |
| **第二代** | Norfloxacin | 最弱 (治UTI)。G(-)：PEcK + HMN + Pseudo。Atypical: mycoplasma, chlamydia, legionella, rickettsia |
| | Lomefloxacin | 被取代。2nd-line anti TB。不含鏈球菌 |
| | Ofloxacin | 唯一對chlamydia杀菌 |
| | Ciprofloxacin (Ciproxin) | 全身殺G(-), PsA最強 |
| **第三代** | Levofloxacin (Cravit) | 第二代 + G(+) (S. pneumonia, viridans，但台灣S. aureus效果差) |
| **第四代** | Moxifloxacin (Avelox) | ① = [2nd G(-) – Pseudomonas] + [↑atypical] + [3rd G(+)] + anaerobes。② 大部分G(+)>G(-)、鏈球菌、厭氧菌。③ Moxifloxacin從腎排出少，故不治UTI或GU感染。 |

**禁忌症：** <18y/o、孕婦、哺乳者禁 (影響軟骨發育)。

**S/E:** QT prolong、tendinitis、tendon rupture、N/V、↓appetite、血糖不穩 (可能高或低)、周邊神經炎、SIADH。

**機轉：** ① 抑制DNA gyrase、Topoisomerase II及IV，使DNA無法複製。② 濃度決定藥效+抗生素後效應。

**藥物動力學：** ① 空腹GI吸收佳 (Sucralfate、制酸劑、鋁鎂鐵鈣鋅影響吸收) → 不可併用。② 穿透力佳。③ 腎臟排泄為主 (除moxifloxacin)。

### Metronidazole (肝代謝)

Anaerobes (橫膈以下)：G(-)為主 (Bacteroides fragilis)，G(+)的Clostridium也有效。Parasite: Entamoeba, Giardia lamblia, Trichomonas, Gardnerella vaginalis。

**機轉：** 代謝後產生有毒物質破壞細菌DNA。

**S/E:** Disulfiram-like reaction, peripheral neuropathy, encephalopathy。

## 改變細胞膜滲透性

### Detergent - GNB

| 藥物 | 特色 |
|------|------|
| **Polymyxin B** | 作為洗腎管路的coating，可以洗GNB菌血症毒素。機轉：和LPS結合用hydrophobic tail導致內外膜分解。 |
| **Colistin (Polymyxin E)** | IV毒性較大，另可做吸入劑治療MDR-GNB肺炎。INH毒性較小，但不建議使用超過1個月。S/E：神經毒、腎毒。Colistin resistance：細菌改變LPS導致，但也造成毒性下降及對其他藥物的sensitivity。Colistin建議和Carbapenem類合用，但不能和tigecycline併用 (預後變差)。 |

### Depolarization - G(+)

| 藥物 | 特色 |
|------|------|
| **Daptomycin (Cubicin)** | 對lung的penetration較差，在含糖溶液中 (D5W、4.5的PD液) 會被degrade，可加在PD液 (1.5%及2.5%) 中治MRSA/VRE peritonitis (20mg/L)。機轉：造成細胞去極化影響DNA、RNA、protein合成。S/E：myopathy (驗CK)、周邊神經病變。 |

### Nitrofuran

| 藥物 | 特色 |
|------|------|
| **Nitrofurantoin** | 治UTI (E. coli)。① 造成pulmonary fibrosis。② G6PD禁用。 |
