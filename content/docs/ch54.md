# ■ 免疫抑制劑 (Immunosuppressive Agents)

## Glucocorticoid (見腎上腺皮質類固醇)

↓NFκB → ↓cytokine

## Calcineurin inhibitor

**機轉：** Calcineurin為一個cytoplasmic phosphatase，可以活化許多T-cell-specific transcription factor，如NF-AT，抑制Calcineurin可以降低T cell的IL-2的合成，抑制了T cell activation。

### Cyclosporine (Sandimmun) PO、IV

| | |
|---|---|
| ① | 為peptide antibiotic，會與cyclophilin結合形成複合體，直接抑制calcineurin。 |
| ② | 肝臟P450代謝 |

| | |
|---|---|
| ① S/E：造成高尿酸、高膽固醇、dose-related nephrotoxicity、HTN、hyperK、gingival hypertrophy、diabetogenic、癲癇、hypo Na、hypo Mg。 |
| ② 不會造成BM suppression，或非常輕微。 |
| ③ < 10mg/kg對胎兒無害 |

---

### Tacrolimus (FK506) (Prograf) PO、IV、EXT

| | |
|---|---|
| ① | 為Streptomyces tsukubaensis製造之macrolide antibiotic，與FKBP結合形成複合體，進而抑制calcineurin。 |
| ② | 肝臟P450代謝 |

| | |
|---|---|
| ① S/E：與 cyclosporine 相同，但較易BM suppression，不會造成血尿胺、高膽固醇。 |
| ② 強度較cyclosporine強10-100倍 |

---

## Proliferation-signal inhibitors (PSIs) = mTOR inhibitor

**機轉：** 與循環中的FK506-binding protein 12結合形成複合體，阻斷mTOR，進而抑制interleukin-driven T-cell增生、B-cell增生、immunoglobulin 製造。

| Drug | Mechanism | Side Effects |
|---|---|---|
| **Sirolimus (rapamycin)** | T₁/₂ = 60h、肝臟P450代謝。 | ① S/E：嚴重的BM suppression（尤其是thrombocytopenia）、肝毒性、腹瀉、高TG、interstitial pneumonitis、headache。<br>② 較少有腎毒性問題<br>③ 治療pNET、RCC、HR+/HER2- breast、renal AML。 |
| **Everolimus (Afinitor) (Certican)** | T₁/₂ = 43h、肝臟P450代謝。 | |

## Mycophenolic acid (MPA) 衍生物

| Drug | Mechanism | Side Effects |
|---|---|---|
| **Mycophenolate mofetil MMF (Cellcept) PO、IV** | 為黴屬 Penicillium glaucus 產生之mycophenolic acid的半合成物，在體內代謝成MPA後，抑制CMP dehydrogenase，阻斷de novo guanine synthesis。 | ① S/E：GI distress、headache、HTN、較少BM suppression（可逆、罕見neutropenia）。<br>② 懷孕前6 mo要換成azathioprine<br>③ Mforitc是enteric-coated MPS，每720 mg = 1000 mg MMF。或減少GI副作用 |

## Thalidomide 及 Immunomodulatory derivatives of thalidomide (IMiDs)

| Drug | Mechanism | Side Effects / Clinical Use |
|---|---|---|
| **Thalidomide (Thado)** | 有很多的機轉，像是抑制TNF-α、phagocytosis等，具抑制血管生成、抗發炎、及免疫調節的功能。 | ① 過去被用在懷孕時的sedation，但是因為造成海豹肢 (phocomelia) 所以停用。目前被用在治療MM、relapsed-refractory disease，也有些研究用在其他癌症上。<br>② S/E：周邊神經病變、便秘、紅疹、hypothyroidism、deep vein thrombosis。 |
| **Lenalidomide (Revlimid)** | 為IMiD，主要是降低thalidomide的致畸胎性，其他副作用相似但程度較輕微。 | 目前用來治療myelodysplastic syndrome、MM。 |
| **Pomalidomide (Pomalyst)** | | 目前用來治療relapsed and refractory multiple myeloma。 |

## Cytotoxic Agents

| Drug | Mechanism | Side Effects |
|---|---|---|
| **Azathioprine (Imuran)** | 在體內代謝成6-MP→de novo purine ↓，因免被細胞主要靠此路徑合成purine，故造成身體細胞無法增生，可阻斷細胞免疫及抗體免疫。 | ① S/E：BM suppression（較常見leukopenia）、NV、發燒、紅疹、肝毒性。<br>② 懷孕可用<br>③ 由XO代謝，故不可和allopurinol並用，會造成BM suppression ↑。 |
| **其他** | Cyclophosphamide、Leflunomide、Hydroxychloroquine、vincristine、methotrexate、cytarabine。 | |

## 劑量 / Dosage（常用劑量整理）

| 藥物 | 商品名 | 劑量 / 用法 |
|------|--------|---|
| Cyclosporine | Sandimmun | 移植：起始4-6mg/kg/day PO，分2次；維持2-4mg/kg/day。GVHD：1-3mg/kg/day IV或3-5mg/kg/day PO。膠囊：25mg、50mg、100mg。 |
| Tacrolimus | Prograf | 移植：起始0.05-0.075mg/kg IV CI或0.1-0.2mg/kg/day PO分2次；維持劑量依血中濃度調整（目標濃度5-15ng/mL）。膠囊：0.5mg、1mg、5mg。 |
| Sirolimus | Rapamune | 負荷劑量6mg PO，之後2mg QD PO。維持：1-3mg QD PO（目標濃度5-15ng/mL）。 |
| Everolimus | Afinitor | 器官移植：0.75-1.5mg BID PO。腫瘤：2.5-10mg QD PO。 |
| Mycophenolate mofetil | Cellcept | 1-1.5g PO/IV BID。 |
| Mycophenolate sodium | Myfortic | 720mg PO BID。 |
| Azathioprine | Imuran | 起始3-5mg/kg/day PO，維持1-3mg/kg/day。 |
| Thalidomide | Thado | 50-400mg QD PO，睡前服用（神經病變风险）。 |
| Lenalidomide | Revlimid | 5-25mg QD PO×21天，停7天（28天療程）。 |
| Pomalidomide | Pomalyst | 4mg QD PO×21天，停7天。 |
