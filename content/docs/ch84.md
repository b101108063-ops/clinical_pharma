# CH84 Asthma 用藥 (Asthma Medications)

**Asthma 是 chronic inflammation + hyperresponsive airway，故使用 corticosteroid (抗發炎) 為第一線。**

## 氣管擴張劑

### 吸入型 β Agonist

| 分類 | 藥物 | 說明 |
|------|------|------|
| **SABA** | Salbutamol (Albuterol)、terbutaline | 急性發作使用，作為緩解藥物 |
| **LABA** | Salmeterol、formoterol | LABA 中的 formoterol 因 onset 快，也可使用於急性發作 |

### 口服 β Agonist

| 藥物 | 劑量 |
|------|------|
| Procaterol (Meptin) | 小兒 (<6 y/o): 5μg/kg QD-BID。成人: 25-50μg QD-BID |
| Fenoterol (Strolin) | 小兒: 0.15-0.25-0.3 mg/kg/d TID-QD |

### 擬交感神經藥物

| 藥物 | 劑量 | 說明 |
|------|------|------|
| **Epinephrine (1:1000 1mg/ml)** | 0.01mg/kg (Max 0.3-0.5mg) Q20min ×3 | 救急用 |

### Methylxanthine

| 藥物 | 說明 |
|------|------|
| **Theophylline (Nosma) (Theo)** | 機轉: 抑制 PDE、阻斷 Adenosine-1 receptor，放鬆支氣管平滑肌。目標血中濃度 10-20 μg/ml。S/E: level < 20 (N/V) ~ level > 20 (失眠、腸胃不適、頭痛)、level > 35 (心悸、癲癇) |
| **Aminophylline (Phyllo-Aminophylline)** | IV: 7mg/kg loading IVD for 20-30min then 0.4mg/kg/hr |

## 抗膽鹼藥物

| 藥物 | 說明 |
|------|------|
| **Ipratropium (Atrovent)** | ① 減少外分泌，放鬆平滑肌<br>② 作用較慢，急性期常與 β2 agonist 混合吸入 |
| **Tiotropium (Spiriva)** | 長效 |

## 抗 Leukotriene 藥物 (LTRA)

| 藥物 | 機轉/說明 |
|------|-----------|
| Zileuton | 直接抑制 5-Lipoxygenase (5-LOX)，減少 leukotriene 製造 (QID) |
| Zafirlukast | Leukotriene-R antagonist (BID) |
| Pranlukast | (BID) |
| Montelukast | (QD) |

**說明:**
- ① Leukotriene-R antagonist，可能造成 Churg-Strauss vasculitis
- ② 對某些病患很有效，特別是 aspirin sensitive asthma
- ③ S/E: 目前無明確副作用，可能導致可逆性肝炎

## 穩定 Mast Cell

## GINA 治療指引 (Global Initiative for Asthma, 2017)

### 治療目標
**Achieve and maintain clinical control**

### 評估指標

| 指標 |
|------|
| ① 日間症狀 (每週 > 2次) |
| ② 日常活動的限制 |
| ③ 夜間症狀或醒來 |
| ④ 需要用緩解藥物 (每週 > 2次) |

### 控制等級

| 等級 | 標準 |
|------|------|
| 控制良好 (Well Controlled) | 以上全部沒有 |
| 部份控制 (Partly Controlled) | 出現 1-2 項 |
| 控制不佳 (Uncontrolled) | 出現 3-4 項 |
| 急性發作 (Exacerbation) | 依照急性發作治療 |

### 藥物選擇

| Step | 非藥物 | 緩解型藥物 | 控制型藥物 |
|------|--------|------------|------------|
| Step 1 | 衛教、環境控制、避免 risk factors | 發作時使用 SABA | — |
| Step 2 | | | 低劑量 ICS |
| Step 3 | | SABA 或低劑量 ICS + formoterol | 低劑量 ICS + LABA |
| Step 4 | | | 中、高劑量 ICS + LABA |
| Step 5 | | | 高劑量 ICS + LABA + 附加治療 (低劑量口服 steroid、tiotropium、omalizumab、mepolizumab) |

### 藥物劑量階梯

| 藥物 | 說明 |
|------|------|
| ICS = inhaled glucocorticosteroids | |
| Leukotriene modifier | 可考慮在 Step 2-4 替代或合併使用 |
| Low dose theophylline | Step 3 起可考虑使用 |
