# CH77 止瀉劑 (Antidiarrheal Agents)

## 抗腸胃蠕動 (Antimotility Agents)

| Drug Name | Dosage | Mechanism/Notes |
|-----------|--------|----------------|
| **Loperamide (Imodium/Imolex)** 強效，一般開 ST | 急性腹瀉: Initial dose: 4mg; 每次腹瀉追加 2mg (Max: 16mg, Traveler's diarrhea 最多不可超過 8mg) | ① 機轉: 活化 Myenteric plexus μ-R (Gi→K⁺↑), 造成過極化，減少 Ach 釋放<br>② 脂溶性低，不通過 BBB，故不具成癮性<br>③ 適應症: 無 fever、無 ileus 可能之腹瀉，及排除感染造成之腹瀉<br>④ <2 y/o 不可使用<br>⑤ 副作用: 肝臟、CNS 毒性 |
| **Codeine** | 10-30mg PO BID-TID | ① 機轉: ↓ ACh 釋放、抑制腸道推進運動、增加水分吸收<br>② 副作用: 成癮 |
| **Diphenoxylate** | 2.5mg/tab | ① 機轉: 活化 Myenteric plexus μ-R |
| **Atropine** | 0.025mg/tab | ① Anti-cholinergic effect |
| **Diphenoxylate + Atropine (Lomotil)** | 2.5mg/Tab, 2# QID; 10ml/day (Max: 20mg) | ① 機轉: 活化 Myenteric plexus μ-R<br>② 不可用於: Shigella、Salmonella 等造成之感染性腹瀉、偽膜性大腸炎、ulcerative colitis (<2 y/o 幼兒、肝/腎功能不佳患者 |
| **Mepenzolate (Trancolon)** | 7.5-15mg (1-2#) TID | ① Anti-cholinergic effect |
| **Butylscopolamine (Buscopan)** | 10-20mg TID-QID | ① Anti-cholinergic effect |
