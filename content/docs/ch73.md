# CH73 泌尿科用藥 (Urology Medications)

bladder neck = α receptor (收縮), detrusor muscle = M2、M3 (收縮)、β receptor (放鬆)。

## Urge Incontinence 治療

**Urge incontinence = detrusor overactivity = detrusor hyperreflexia**：漏尿 + 無法憋尿。

### Anti-M (效果差不多) - 直接抑制 detrusor muscle contraction

| 藥物 | 劑量/特性 |
|------|----------|
| Oxybutynin (Ditropan) (Oxbu ER) | 另可直接放鬆肌肉。2.5-5mg TID-QID |
| Tolterodine (Detrusitol) | 4mg QD |
| Propiverine (Urotrol) | 另有 Ca antagonist 作用 |
| Trospium | |
| Solifenacin (Vesicare) | 5mg QD |
| Darifenacin | 對 bladder 選擇性高 |
| Flavoxate (Genurin) (Foxate) | 200mg TID-QID，evidence 較弱，具平滑肌抗痙攣效果。 |

### α blocker - 用在有 BPH 的男性，放鬆膀胱頸，以增加尿液排出。女性使用也有效。

| 藥物 | 劑量/特性 |
|------|----------|
| Tamsulosin (Harnalidge D) (Tamlosin) | 0.4-0.8mg QD |
| Silodosin (Urief) | |
| Alfuzosin | |
| Prazosin | |
| Terazosin | |
| Doxazosin (Doxaben) | 4-8mg QD，比較常用來降血壓。 |

**S/E**: Orthostatic hypotension、dizziness。Tamsulosin 及 Silodosin 作用在 α₁ₐ 更具選擇性。

### Botulinum toxin

| 藥物 | 給藥方式 | 機轉 |
|------|---------|------|
| Botulinum toxin | 注射到 submucosa | 阻斷神經末梢釋放 Ach、ATP，抑制膀胱感覺神經及副交感神經。 |

## Stress Incontinence 治療

**Stress incontinence**：當出力時無法控制的漏尿。

| 類別 | 藥物 | 劑量 | 機轉/S/E |
|------|------|------|---------|
| TCA | Imipramine | 10-20mg HS | S/E：orthostatic hypotension。 |
| SNRI | Duloxetine | | 減少 serotonin 及 NE 回收，增強 pudendal nerve 對外括約肌的反射，增強收縮力。 |

## Overflow Incontinence 治療

**Overflow incontinence = incomplete emptying**：解不乾淨。

| 類別 | 藥物 | 劑量 | 機轉 |
|------|------|------|------|
| Cholinergic | Bethanechol (Dampurine) | 10mg TID | 增強 detrusor muscle contraction |
| | Neostigmine | | |
| α blocker | 同上 | | |
| Other | Baclofen | | |

## Mixed Incontinence 治療

**Mixed incontinence = urge incontinence + stress incontinence**

**Overactive bladder** = urgency (急迫感) + frequency (白天 > 8次) + nocturia (起床 > 1次), ± incontinence (來不及到廁所就尿)

| 類別 | 內容 |
|------|------|
| 非藥物 | 膀胱訓練、生理回饋、電刺激、磁波刺激。 |
| 藥物 | Anti-M、β3 agonist、α blocker (?) |

## Interstitial Cystitis, GU Irritation

| 類別 | 藥物 | 機轉 | S/E |
|------|------|------|-----|
| Local anesthesia | Phenazopyridine (Urogen) (Uroprin) | 經尿排出，對 mucosa 有局部麻醉效果。 | S/E：橘色尿、紅色尿、HA。 |

## BPH 治療

- 針對 obstructive symptoms：α blocker、5α reductase inhibitor。
- 針對 irritative symptoms：5α reductase inhibitor、antidepressant。
