# CH81 祛痰、化痰、止咳藥、感冒藥 (Mucoactive Drugs)

## 祛痰藥物分類表

### 排痰劑 (Expectorant)

能促進 mucus 排出，改善 mucus 塞住氣道之症狀。

| 分類 | 藥物 | 作用/機制 | 副作用/備註 |
|------|------|----------|------------|
| 含碘物質 | KI、Iodinated glycerol、domiodol | 臨床上使用有爭議，因為有 toxicity。Iodinated glycerol 另具有止咳效果。 | 刺激 gastric vagal receptor 造成副交感興奮 → glandular exocytosis 分泌水性 mucus |
| Ion-channel modifier | | P2Y2 purinergic receptor agonist，改善 ciliary clearance。 | |
| Hypertonic saline inhalation | | 使痰液變稀減少黏滯力，主要用在刺激咳痰作 diagnosis。 | |
| Guaifenesin (Glyceryl guaiacolate) (Robitussin) (Unitussin 20mg/ml) | 降低氣管內痰液的表面張力，但沒有 RCTs 證據支持其效果。1/4 BW ml Q6H | S/E: 口乾、N/V、rash、GI upset |

### 化痰劑 (Mucolytic)

分解黏液、降低黏稠度。

**黏液成分**: 水、醣蛋白、蛋白質、脂質、低分子量離子。

**痰液成分**: 發炎物質 + 黏液，有 PMN、DNA、F-actin、細胞或細菌殘骸。

| 分類 | 藥物 | 作用/機制 | 副作用/備註 |
|------|------|----------|------------|
| **Classical mucolytics** | 經由 free thiol group 把黏液素醣蛋白間的雙硫鏈分解 | | |
| | **Acetylcysteine (NAC) (Actein) (Fluici) 吸入 (Encore)** | ① Inhalation<br>② 化痰: 成人 1 sachet TID PO；小兒 1 sachet/40kg/dose TID<br>③ 解 Acetaminophen 中毒: 140mg/kg st + 70mg/kg x 17 dose<br>④ 預防 CIN: 1200mg BID，contrast 前給 1-2 dose，總共給 48h，效果仍具爭議性 | S/E: 支氣管痙攣 (asthma attack 不用)、N/V。對穩定的 COPD 病人可提高日常功能 |
| | Nacystelyn (Lysine salt of NAC, NAL) | 改變 NAC 結構使其由酸性變成中性，可降低呼吸道刺激 | |
| | Mesna (2-mercaptoethane sulphonate) | ① 具強抗氧化功能，治療 Cyclophosphamide 的出血性膀胱炎<br>② 吸入性藥物 | S/E: HTN、rash、N/V、nephrotoxicity |
| **Peptide mucolytics** | | | |
| | Domase alga | 分解 DNA 的聚合物 | 對 cystic fibrosis 病人有效 |
| | Gelsolin、thymosin b4 | 分解 F-actin 的聚合物 | 尚未臨床使用 |
| **Non-destructive mycolytics** | | | |
| | Dextran | 破壞黏液間的氫鍵及增加分泌物水分 | 臨床效果未證實 |
| | Heparin、LMWH | 破壞黏液間的氫鍵和離子鍵 | |

### 黏液調節劑 (Mucoregulator)

調控 mucus secretion 或干擾 DNA/F-actin network，以漸少分泌物。

| 藥物 | 作用/機制 | 副作用/備註 |
|------|----------|------------|
| Carbocisteine | 具抗氧化及抗發炎效果。RCT (PEACE study): 在 COPD 病人可以減少發作並提升 QoL | |
| Anticholinergic: atropine, ipratropium, tiotropium | 阻斷 M₃，造成 glandular 分泌減少。Atropine 另外可以影響 mucociliary clearance | |
| Steroid PO 或 inh | 增加 mucociliary clearance，但減少分泌的效果不大 | |
| Macrolide: erythromycin, azithromycin, clarithromycin | 免疫調節，可 ↓ PMN chemotaxis，並調節呼吸道 smooth muscle 及 neural tone | 在 cystic fibrosis 病人有效，對 COPD 病人證據不明 |

## 吸入劑 (Inhalation)

| 藥物 | 適應症 | 副作用 |
|------|--------|--------|
| Bricanvl (Terbutaline) | 支氣管痙攣 | HR 上升 |
| Atrovent (Ipratropium) | 支氣管痙攣 | 口乾、咳嗽 |
| Encore (Acetylcysteine) | 氣道黏液太黏稠、支氣管痙攣 | |
| Siruta (Mesna) | 氣道黏液太黏稠、支氣管痙攣 | |
| Jusomin (3% normal saline) | 誘發咳嗽以收集痰檢、支氣管痙攣 | |
| Bosmin (Epinephrine) | 支氣管痙攣性咳嗽、stridor、咳血 | |
