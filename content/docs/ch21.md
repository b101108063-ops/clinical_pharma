# 抗心律不整藥 (Antiarrhythmic Drugs)

## Singh-Vaughan Williams Classification

| Class | 作用 | 藥物 |
|-------|------|------|
| **Ia** | Na channel blocker + K channel blocker | Quinidine, Procainamide, Disopyramide |
| **Ib** | Phase 2 Na blocker | Lidocaine, Mexiletine, Phenytoin |
| **Ic** | Na channel blocker + K channel blocker | Flecainide, Propafenone |
| **II** | β-blocker | Propranolol, Esmolol |
| **III** | K channel blocker | Amiodarone, Sotalol, Dofetilide, Ibutilide |
| **IV** | CCB | Diltiazem, Verapamil |

## Class I — Na Channel Blockers

### Class Ia

| 藥物 | 適應症 | S/E |
|------|--------|-----|
| **Quinidine** | 治療廣泛(V、T、AF、AFL) | ①金雞納中毒(Cinchonism)：頭暈、耳鳴 |
| | | ②心室心律不整（因 QT 延長的 TdP）：最易引起 |
| | | ③骨骼肌鬆弛（因類似 Atropine 的抗 M 作用）|
| | | ④會↑HR（因抗 M 作用）→ 故目前已不用於治療 SVT |
| **Procainamide** | V、AF、AFL、PSVT | Lupus-like syndrome = 發燒、關節痛 |
| | | 治療 digitalis-induced ventricular arrhythmia |
| | | 毒性高且目前少用 |
| **Disopyramide** | Paroxysmal SVT | 抗膽鹼作用：口乾、視力模糊、尿滯留 |
| | | VNF |

### Class Ib

| 藥物 | 適應症 | 特色 |
|------|--------|------|
| **Lidocaine** | V、VT、VF | ①唯一針劑 β-blocker |
| | | ②心室相關 |
| | | ③150mg IV bolu, 1-2mg/kg |
| | | ④ onset 5-10min, duration 15-30min |
| **Mexiletine** | VT/VF（口服）| ①口服首渡效應大 |
| | | ②肝臟代謝：肝功能差劑量應增加 |
| **Phenytoin** | ①一般併用 amiodarone 者 |
| | | ②治療 digitalis-induced arrhythmia |
| | | ③也可做局部麻醉藥 |

### Class Ic

| 藥物 | 適應症 | S/E |
|------|--------|-----|
| **Flecainide** (Tambocor) | VT、AF、WPW | 會↑HR（因→AF）|
| | Afib 預防 | 禁用於心臟結構異常 |
| | | 治療 VT 會↑mortality |
| **Propafenone** (Rytmonorm) | ①有 β-blocker 作用 |
| | | ②禁用於心臟結構異常 |
| | | 治療 VT 會↑mortality |

## Class II — β-Blockers

| 藥物 | 適應症 | 特色 |
|------|--------|------|
| **Propranolol** | AF、AMI 後復發的心律不整 | |
| | SVT | |
| **Esmolol** | ①AF | 非常短效 |
| | ②交感活性引發，如手術或緊急情況 | 唯一靜脈注射 β-blocker |

## Class III — K Channel Blockers

### Amiodarone (Cordarone)

| 項目 | 內容 |
|------|------|
| T1/2 | >50 days |
| 機轉 | 同時具有 Class I、II、III、IV 作用 |

#### 適應症

- VT/VF/NSR
- AFL、AFib
- SVT
- 其他療效不佳時的首選

#### S/E（副作用）

1. 肺毒性
2. 光敏感
3. 色素沉著
4. 甲狀腺異常（甲狀腺亢進/低下）
5. 肝臟毒性（AST/ALT >3 ULN 或 >2x baseline 須停藥）
6. 角膜沉積物 (corneal microdeposits)
7. 皮膚 (violaceous discoloration)
8. 對甲狀腺有 anti-toxic effect → destructive thyrotoxicosis

#### 交互作用

- 與 Digoxin 或 Warfarin 合併使用：Digoxin、Warfarin 應減量

#### 劑量

| 給藥方式 | 劑量 |
|----------|------|
| VF/pulseless VT | 300mg → 150mg |
| VT/VF (conversion rate 60%) | 150mg IVD over 10 min → 0.5-1 mg/min × 24h |
| Tachyarrhythmia | 150mg IVD over 10 min |
| 慢性治療 | 200mg PO TID 逐漸 ↓至 QD |

### Sotalol (Cardol)

| 項目 | 內容 |
|------|------|
| 組成 | D-sotalol (K blocker) + L-sotalol (β-blocker) |
| 適應症 | AF、VT/VF (conversion rate 70%) |
| 禁忌症 | Decompensated CHF |
| S/E | TdP、SB、AVB |

### Dofetilide

| 項目 | 內容 |
|------|------|
| 機轉 | Block IKr → QT prolong |
| 適應症 | AF、AFL |
| 代謝 | 腎臟代謝 |
| Conversion rate | AF (45%)、AFL (60%)，對 persistent AF 效果不好 |
| S/E | ↑3-8% TdP（一般在給藥後 2-4h）|

### Ibutilide

| 項目 | 內容 |
|------|------|
| 適應症 | AFL、AFib conversion |
| 特色 | 唯一 FDA 核准之藥理性 cardioversion |

### Dronedarone (Multaq)

| 項目 | 內容 |
|------|------|
| 機轉 | Block IKr → QT prolong；去掉 amiodarone 中的 I → 少了甲狀腺、肺 S/E |
| 適應症 | AF（降低 non-permanent AF 的 mortality）|
| S/E | 不影響 CHF，不會造成 SA node dysfunction 或 AV block |
| 禁忌症 | CHF (NYHA FC ≥ III)、Permanent AF（因↑HF、中風、CV death）|

## Class IV — CCB

| 藥物 | 機轉 | 適應症 | S/E |
|------|------|--------|-----|
| **Diltiazem** | ↓SA/AV node → AV conduction↓ → PR prolong | AF、AFL、PSVT | 心臟無力 |
| | | MAT | |
| | | SVT | |
| **Verapamil** | 同上 | AFL、PSVT (s/p adenosine)、MAT、AFib | 同上 |
| | | SVT | |

### 劑量

| 藥物 | 劑量 |
|------|------|
| **Diltiazem** | 15-20mg IV for 2 min (0.25mg/kg), then 20-25mg for 15min (0.35mg/kg) |
| **Verapamil** | 2.5-5mg IV for 2 min, then 5-10mg for 15-30min |

## 其他抗心律不整藥

### Adenosine

| 項目 | 內容 |
|------|------|
| 機轉 | ① SA/AV node → PR prolong |
| | ② 支氣管痙攣（數秒）|
| | ③ 毒性低 |
| | ④ 對 AV node 主→↓HR、↓SV |
| 適應症 | AF、PSVT、SVT（首選）|
| 劑量 | 6mg IVP → 12mg IVP（最大）|
| | + N/S flush (20ml) |
| 禁忌症 | Allergy、asthma、WPW（可能引起 AF）|

### Digoxin

| 項目 | 內容 |
|------|------|
| 機轉 | 延長 PR interval → ↓HR、↑SV |
| 適應症 | SVT, PSVT, AF w/ CHF |
| 劑量 | 0.5mg IVP, Max 3mg |

### Atropine

| 項目 | 內容 |
|------|------|
| 適應症 | 治 Sinus bradycardia |
| 劑量 | 0.5-1mg IVP |

### MgSO₄

| 項目 | 內容 |
|------|------|
| 機轉 | 機轉不明，專治 Torsades de Pointes |
| Pulseless TdP | 1-2g in 10ml N/S or D5W IVD for 1-2min or IVP |
| Tachycardia TdP | 1-2g in 50-100ml D5W IVD for 5-60 min |

## 抗心律不整藥物對心電圖的影響

| 影響 | 藥物 |
|------|------|
| ↑PR interval | 造成 AV node block 的藥物：Adenosine > Class I |
| ↓QRS duration | Class I |
| ↑QT interval | K channel blocker：Class Ia > III |

## 臨床選藥原則

### Ventricular arrhythmia 治療

| 情況 | 首選藥物 |
|------|----------|
| Post-MI | Lidocaine 或 Mexiletine |
| Digoxin-induced | Phenytoin |
| QT prolong >550ms | Lidocaine |
| 一般情況 | Amiodarone |
| Torsades de Pointes | MgSO₄ |

### AF rate control

- β-blocker
- CCB
- Digoxin
- 注意：低血壓會↓（要先確保 fluid 足夠）

### AF rhythm control

- Class Ic（if w/o structural dz）
- Amiodarone（if w/ structural dz）
- Sotalol, Dofetilide

### SVT 治療

- β-blockers
- K channel blockers
- CCB
- Adenosine
- Digoxin

> **注意**：只有 β-blockers 可提高 post-MI arrhythmia 存活率
