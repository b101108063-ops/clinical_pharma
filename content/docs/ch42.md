# 鴉片類藥物 (Opioid Analgesics)

大多數藥物為肝代謝、腎排出→肝不好 (調整dose)，腎不好 (如果代謝物無活性則不用調整劑量)。

## Full Agonist

無ceiling effect，合併使用不同full agonist藥效可以加乘。

## Mixed Agonist/Antagonist

有ceiling effect，禁止併用full agonist (因無合併藥效、難以預測交互作用)。

| 藥物 | 作用/特色 | S/E |
|------|-----------|-----|
| **Nalbuphine (Bain)** 10-20mg IV/IM/SC Q3-6H Ceiling 160mg/d | ① κ agonist + weak μ antagonist。② 較morphine不會產生膽絞痛。 | ① Nausea/vomiting (比morphine嚴重)。② 呼吸抑制 (與morphine相同，但會有ceiling effect)。 |
| **Buprenorphine (Temgesic)** T₁/₂: 37h (SL), 2.2h (IV) Ceiling 1.6 mg/day 舌下 | ① κ antagonist + partial μ agonist，且對μ receptor affinity強。② 重度opioid依賴者不適用，因為效果沒有morphine好且一旦結合morphine也無法競爭。③ 因S/E較少，因此逐漸取代Methadone成為Morphine戒斷替代品。④ Naloxone解毒效果不好 (因為affinity強)。⑤ Liver CYP3A4代謝，high dose會導致hepatitis，糞便排出→腎不好不用調dose，肝不好要小心。 | |
| **Butorphanol** | κ agonist + weak μ antagonist/partial agonist，容易產生sedation。 | |
| **Pentazocine** | κ agonist + weak μ antagonist/partial agonist，高劑量會引起焦慮現象。 | |

## Pure Antagonist

對μ有high affinity，對δ、κ較弱。

| 藥物 | 作用 |
|------|------|
| **Naloxone** Peak 1-2 min Duration 30 min | ① 肝臟代謝。② 拮抗opioid在大腦及脊髓之作用，治療CNS抑制或呼吸抑制。③ 可通過胎盤，分娩前給可減少opioid導致之新生兒呼吸抑制。④ S/E：肺水腫、cardiac arrest、疼痛 (因為opioid被阻斷)、morphine withdrawal syndrome。劑量：0.4-2mg q1-2min IV, Max 10mg。 |
| **Naltrexone** PO, nalmefene IV | Duration約10小時。 |
| **Alvimopan, methylnaltrexone** | 為Peripheral μ antagonist，在GI可以治療opioid-induced ileus，很少有CNS penetration。 |

## Morphine 詳細內容

**內生啡：** ① μ → Endorphins (目前臨床止痛仍以此為主)。② δ → Enkephalins。③ κ → Dynorphins。

**機轉：** 主要作用於μ、κ receptor → G_i → ① Ca²⁺↓ ② 打開K⁺通道。

## 常用考量

1. **耐藥性 (tolerance)：** morphine劑量需要增加一般代表疾病變嚴重，而非耐藥性。副作用除了縮瞳、便秘外皆會產生耐受性。

2. **生理依賴性 (dependence)：** 長期使用的患者突然中斷或降低劑量會產生withdrawal syndrome。預防方法：① 避免使用partial agonist或mixed agonist/antagonist，尤其是病人已經在使用full agonist。② 非必要勿使用naloxone。③ 緩慢減量。

3. **成癮性 (addiction)：** 一般是病人心理的問題。

**特別注意：** 頭受傷（因會致IICP）、膽絞痛、膽結石、BPH、asthma（直接有bronchospasm）、孕婦。

## 副作用及其處置

| 系統 | 副作用 | 處置 |
|------|--------|------|
| 腸胃道 | 噁心、嘔吐、便秘 | 軟便劑、止吐劑、低劑量haloperidol |
| 腸胃道 | 增加膽道壓力，誘發膽絞痛 | 選用Mixed agonist/antagonist較不會產生 |
| 自主神經 | 口乾、尿滯留、姿勢性低血壓 | 放Foley |
| 中樞神經 | 嗜睡、delirium、myoclonus、seizure、幻覺、hyperalgesia | 中樞神經刺激劑、haloperidol、anticonvulsant |
| 中樞神經 | 昏迷、呼吸抑制（很少見，在① OSAS ② brain lesion病人要注意） | 給naloxone |
| 皮膚 | 癢、出汗 | |

**中毒：** 針狀瞳孔、呼吸抑制 (RR < 8-10 cpm)、昏迷、低血壓。

**解毒劑：** Naloxone（注射，緊急拮抗劑，0.4-2mg Q1-2min, Max 10mg）、Naltrexone（口服、少用）、Methadone（戒斷替代品）。

**不因對Opioids產生耐受性而消失的症狀：** 縮瞳、便秘、拮抗劑之效果 (antagonist actions)。

**Opioid-sparing effect：** 指併用其他止痛藥可以有效降低opioid的使用劑量，如NSAID、acetaminophen、clonidine、dexmedetomidine。
