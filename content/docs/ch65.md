# Progestogens / progestins 黃體素結合劑

| (Nath & Sitruk-Ware, 2009) | | | A | AntiA | C | AntiM | A: androgen、C: glucocorticoid、M: mineralocorticoid |
|---|---|---|---|---|---|---|---|

## Progesterone / Androgen R / Estrogen R / Glucocorticoid R / Mineralocorticoid R

**OCPs are 19-nortestosterone**
**HRT is 17-hydroxyprogesterone**

### 第一代 Estranes (Estrigerone, 19-nortestosterone) 來
- 人體的
- Norethisterone acetate
- Lynestrenol
- (+, -, -, -)

### 第二代 Pregnanes (Progesterone, 17-hydroxyprogesterone) 來 ↑ estrogen effect
- Medroxyprogesterone acetate (MPA) (Provera): (±, -, ±, -)
- Cyproterone acetate: (+, -, -, -)
- Chlormadinone acetate
- Megestrol acetate (Megace)
- 目前HRT最常用的Progestin
- Cancer cachexia 進食慾、乳癌、子宮內膜癌

### 第三代 Gonanes (Estrigerone, 19-nortestosterone) 來
- Norgestrel
- Levonorgestrel (後定諾): (+, -, ±, -)
- 事後丸，72hrs內服用1#，12hrs後再服用1#

### 第四代 19-norprogestogens (19-norpregnanes)
- Nestrone: (-, -, -, -)
- Nomegestrol acetate: (-, ±, -, -)
- Trimegestone: (-, +, -, ±)
- Dienogest (Estranes non-ethinylated): (-, +, -, -)
- Drospirenone (Spironolactone derivative): (-, +, -, -)
- 和aldosterone結構相似，會有利尿的效果。

**Summary:**
- High progestational activity (19-norpregnanes: trimegestone > Nestorone > nomegestrol acetate)
- Antiestrogenic (19-norprgnanes > gonanes); Androgenic (gonanes > estranes)
- Antiandrogenic (cyproterone acetate > dienogest > drospirenone > trimegestone)
- Antiminaralocorticoid (drospirenone >> trimegestone); Glucocorticoid (medroxyprogesterone acetate > gestodene)
