# CH69 口服避孕藥 (Oral Contraceptive Drugs)

## 風險與益處總覽

- ↑ Breast cancer (1.19X，但短期使用沒有差 by CARE study)
- ↑ Cervical cancer (1.5X，但可能是因為沒有使用其他避孕物品導致 STD 或 HPV 感染)
- ↓ Ovarian cancer & EM cancer (下降比例和使用時間有關)
- ↓ Colorectal cancer
- ↑ MI (smoker、age>35)
- ↑ Ischemic stroke (migraine、smoker、age>35)
- ↑ Hemorrhagic stroke (age>35)
- ? DVT (和 estrogen dose 有關)

## 漏吃 OCPs 處理原則

1. 平常吃 30-35μg E：漏吃 1-2d → 吃回去；漏吃 ≥3d → 吃回去 + 其他避孕方式 + 7天內避免性行為。
2. 平常吃 20μg E：漏吃 1d → 吃回去；漏吃 ≥2d → 吃回去 + 其他避孕方式 + 7天內避免性行為。
3. 如果是在第3週漏吃 (active form 的最後7顆)：要直接跳過 inactive form 並且吃完下一個 cycle 才算 OK。
4. Inactive form 沒吃到：不須處理。

## 緊急避孕 (Emergency Contraception)

1. < 72h 內吃第一劑，12h 內吃第二劑，E+P 可下降 75% 懷孕率，P only 可下降 89% 懷孕率，越早使用，成功率越高。
2. 目的是干擾子宫內膜影響著床，而非防止排卵 (但可以 delay 排卵)。
3. **P only drug**：Escapelle 1# x 2 dose 或 Postinor-2 2# x 2 dose.
4. **E+P**：No.3 2# x 2 dose.
5. **RU486 600mg**
6. **Danazol**

## Dysfunctional Uterine Bleeding 調經

High dose OCPs，像是給 Diane-35 TID 3天，之後 BID 2天，沒出血就停藥。
