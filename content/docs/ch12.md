# Arachidonic Acid Cascade

## Cascade 流程

- Cell membrane phospholipid → PLA₂ → Arachidonic Acid
- Arachidonic Acid → P450 → EETs, HETEs
- Arachidonic Acid → Free radical → Isoeicosanoid
- Arachidonic Acid → COX-1, COX-2 → PGG2 → COX-1, COX-2 → PGH2 → PGD2, PGE2, PGF, PGI2 (prostacyclin), TXA2 (thromboxane)
- Arachidonic Acid → 5-LOX → 5-HPETE → 5-LOX → LTA4
- LTA4 → LTC4 synthase → LTC4, LTD4, LTE4
- LTA4 → LTA4 hydrolase → LTB4

**圖1** arachidonic acid cascade。Eicosanoid 包含 prostaglandins、prostacyclins、thromboxanes、lipoxins 和 leukotrienes。Prostanoid 包含 prostaglandins、prostacyclins、thromboxanes。Lipoxins 包含 LTA₄ 及 LTB₄。Slow-reacting substance of anaphylaxis (SRS-A) 包含 LTC₄ 及 LTD₄。
