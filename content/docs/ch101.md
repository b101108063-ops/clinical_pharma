## 使用說明與常用抗生素劑量

### 圖例說明

| 符號 | 意義 |
|------|------|
| + | 通常有效 (>60% 感受性) |
| ± | 部分有效 (30-60% 感受性) |
| 0 | 無效或 <30% 感受性 |
| S | 與penicillins有加成作用 |
| 空白 | 資料未提供 |

### 注意事項

1. 本表為参考用，實際抗生素選擇應依據病人臨床狀況、當地抗藥性菌種盛行率及體內藥物動力學調整
2. 肾功能或肝功能不良者需调整剂量
3. 抗生素联合治疗建议咨询感染科
