## 各類 PDE 抑制劑詳解

### PDE 3 抑制劑 (↑cAMP)

| 藥物 | 適應症 | 說明 | 劑量 |
|------|--------|------|------|
| Enoximone, Milrinone | Heart failure | 強心劑 | Milrinone：IV bolus 50 μg/kg，維持 0.375-0.75 μg/kg/min |
| Cilostazol | 抗血小板聚集 | 治療間歇性跛行 | 100mg BID（飯前30min或飯後2h） |
| Anagrelide | 血小板過多症 | | 起始 0.5mg BID，，最大至 10mg/day 或 2.5mg QD |

### PDE 4 抑制劑

| 藥物 | 適應症 | 說明 | 劑量 |
|------|--------|------|------|
| Roflumilast (Daxas) | Asthma、COPD | | 300μg QD（起始），500μg QD（維持） |
| Ibudilast (Ketas) | 支氣管氣喘 | | 10mg BID |
| Apremilast (Otezla) | 乾癬性關節炎 | | 起始 Day1 10mg QD → Day2 10mg BID → Day3 10mg AM/20mg PM → Day4 20mg BID（維持） |

### PDE 5 抑制劑 (↑cGMP)

| Tadalafil | 犀利士 (Cialis) | | Erectile dysfunction | 10mg PRN（性行為前30-60min），可調至20mg；每日固定：2.5-5mg QD |
