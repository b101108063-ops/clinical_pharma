# 抗病毒藥

## 抗皰疹病毒藥 (Anti-herpesvirus)

### 藥物總覽

| 藥物 | 適應症 | 副作用 |
|------|--------|--------|
| **Acyclovir (Zovirax)** | HSV、VZV | 腎毒性、神經毒性 (意識障礙) |
| **Valacyclovir (Valtrex)** | HSV、VZV、CMV | 較少腎毒性 |
| **Famciclovir** | HSV、VZV | 頭痛、噁心 |
| **Ganciclovir (Cytovene)** | CMV視網膜炎 | 骨髓抑制 (中性球減少、血小板減少)、腎毒性 |
| **Valganciclovir** | CMV | 同ganciclovir |
| **Cidofovir** | CMV視網膜炎 | 腎毒性、葡萄膜炎 |
| **Foscarnet** | CMV、acyclovir抗藥之HSV/VZV | 腎毒性、電解質異常 (低鈣、低鎂、低鉀) |

### 劑量參考

| 疾病 | 藥物 | 劑量 |
|------|------|------|
| 唇皰疹 (HSV) | Acyclovir | 200mg PO 5x/day x 5-10d 或 400mg PO BID |
| 生殖器皰疹 | Acyclovir / Valacyclovir | Acyclovir 200mg 5x/d 或 Valacyclovir 1g BID |
| 水痘 (VZV) | Acyclovir | 800mg PO 5x/day x 7d |
| 帶狀皰疹 | Acyclovir / Valacyclovir / Famciclovir | Valacyclovir 1g TID x 7d |
| CMV視網膜炎 | Ganciclovir / Valganciclovir / Foscarnet / Cidofovir | 誘導期後維持治療 |

## 抗病毒藥物使用原則

1. 病毒感染的治療需早期開始，效果更佳。
2. 抗病毒藥物多有肝、腎毒性，需監測肝腎功能。
3. 某些抗病毒藥物有致畸胎性，懷孕用藥需審慎評估。
4. 抗藥性病毒的產生是治療失敗的主要原因之一，需規則服藥。
5. 雞尾酒療法 (HAART) 可大幅降低愛滋病死亡率。
