# 杀菌类伤口照护药物 (Antiseptic Wound Care Agents)

## 外用藥水抗菌範圍

| | G(+) | G(-) | Acid-fast | Lipophilic virus | Hydrophilic virus | 孢子 | 黴菌 | Amebic cyst | Prion |
|---|---|---|---|---|---|---|---|---|---|
| **Alcohol** | +++ | +++ | ++ | ++ | variable | - | | | - |
| **Chlorhexidine** | +++ | + | - | variable | - | - | | | - |
| **Povidone iodine** | +++ | ++ | ++ | ++ | - | ++ | ++ | ++ | - |
| **H₂O₂** | +++ | variable | - | ++ | - | - | - | - | - |

- **Lipophilic virus (enveloped virus)**：如HSV、HIV、CMV、RSV、influenza virus、vaccinia virus、HCV。
- **Hydrophilic virus**：如rotavirus、adenovirus、enterovirus。
- **酒精消毒無效：**含芽孢 (C. difficile、B. anthracis、B. cereus)、阿米巴原蟲、無套膜病毒 (Adenovirus、Enterovirus、HAV、Norovirus)。

## 燒燙傷用藥

| 藥物 | 商品名 | 抗菌範圍 | 備註 |
|------|---------|---------|------|
| Mupirocin | Bactroban | 對G(-)及Enterococci無效。專殺MRSA。 | 具刺激性 |
| Silver sulfadiazine | Sulfasil Cream、Canflame cream | 抗G(+) + G(-) (含PsA) | 用銀離子作杀菌效果，磺胺類藥。常用在燒燙傷病患。 |

## 劑量 / Dosage

### 外用消毒劑稀釋與用法

| 消毒劑 | 濃度 | 稀釋方式 | 用法 | 頻率 |
|--------|------|----------|------|------|
| **Chlorhexidine** | 0.05% (沖洗用) | 原液稀釋40倍 (例：0.5%→0.05%) | 沖洗傷口、術前皮膚消毒 | 每次換藥時 |
| **Chlorhexidine** | 0.5% (皮膚消毒) | 原液使用 | 手術前皮膚消毒、靜脈穿刺前 | 手術前/穿刺前 |
| **Povidone-iodine** | 10% (原液) | 稀釋10-20倍 (0.5-1%) | 沖洗感染傷口 | 每日1-2次 |
| **Povidone-iodine** | 10% (原液) | 原液或稀釋5倍 | 術前皮膚消毒 | 手術前 |
| **Hydrogen peroxide** | 3% (原液) | 稀釋一倍 (1.5%) | 沖洗傷口、去除壞死組織 | 每次換藥時 |
| **Alcohol (Ethanol)** | 70-75% | 原液使用 | 完整皮膚消毒、器械浸泡 | 手術前/穿刺前 |
| **Silver sulfadiazine** | 1% cream | 塗抹厚層 (1-2mm) | 燒燙傷面積>20%時 | 每日1-2次 |
| **Mupirocin** | 2% ointment/cream | 薄層塗抹 | MRSA感染傷口 | 每日2-3次 |

### 沖洗液製備

| 沖洗液 | 配方 | 容量 | 用途 |
|--------|------|------|------|
| **生理食鹽水 (N/S)** | 0.9% NaCl | 500-1000ml/次 | 一般傷口沖洗 |
| **Chlorhexidine 0.05%** | 0.5%稀釋10倍 | 500ml/次 | 感染傷口 |
| **Povidone-iodine 0.5-1%** | 10%稀釋10-20倍 | 250-500ml/次 | 感染或污染傷口 |
| **H₂O₂ 1.5%** | 3%稀釋一倍 | 250-500ml/次 | 去除壞死組織 |
| **Acetic acid 0.25-1%** | 稀釋後使用 | 250-500ml/次 | 銅綠假單胞菌感染 |

### 注意事項

1. 碘製劑 (Povidone-iodine) 禁止與銀製劑 (Silver sulfadiazine) 併用，會降低療效
2. Chlorhexidine 禁止用於眼睛、中樞神經系統、慶大自然腔道沖洗
3. 酒精類消毒劑禁止用於開放性傷口或黏膜
4. Silver sulfadiazine 為磺胺類藥物，對磺胺過敏者禁用
5. Mupirocin 對銀離子過敏者禁用
