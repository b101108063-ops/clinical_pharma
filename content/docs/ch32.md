# 精神科常用抗副作用藥物

## NMS (Neuroleptic Malignant Syndrome)

因影響 dopamine transmission。

### 臨床表現

1. 肌肉僵硬（Muscle rigidity）
2. 高熱（Hyperthermia > 37.2°C）
3. 自主神經功能障礙（Autonomic dysfunction）
4. 意識改變（Altered consciousness: agitation ↔ stupor）

通常在用藥後 1-3 天發生，症狀為 gradual onset。

### Lab 參考

| 項目 | 說明 |
|------|------|
| **CK** | 最具參考價值，可達數十萬 |
| **WBC** | 上升 |

### 處置

停用抗精神病藥物 + 支持性療法。預防脫水，處理併發症（例如 pneumonia, renal failure 等）。

| 藥物 | 說明 |
|------|------|
| **Fluid supply** | 補液 |
| **Dantrolene** | 肌肉鬆弛劑 |
| **Bromocriptine** | Dopamine agonist |

### 流行病學

大多數是典型藥物引發的（發生率 0.02-3.23%），原因不明，死亡率可達 20%。

## PTSD 藥物建議

最好是用 behavioral therapy。

| 建議 | 說明 |
|------|------|
| **SSRI** | 唯一有 evidence 且 FDA approve 的藥，dose 同 MDD |
| **新一代 antidepressant** | 若病人合併 MDD 可以使用 |
| **Atypical antipsychotics** | 不建議使用 |
| **BZD** | 可以當 addictive drug |
| **其他** | 文獻上有人使用，但 evidence 不足：prazosin、TCA、MAOIs |

## 精神科常用抗副作用藥物

| 藥物 | 機轉 | 劑量 | 用途 |
|------|------|------|------|
| **Trihexyphenidyl = benzhexol (Artane)** | 阻斷 Acetylcholine 在腦部細胞的作用 | max 15mg/day, start 1-2mg/day | Akineton 效果約為 Artane 的兩倍；帕金森症候群之震顫麻痺（tremors）及肌肉僵直（rigidity）徵狀，EPS |
| **Biperiden = bipiden (Akineton)** | 同上 | 1amp IM q30min（max 10-20/day）或 2mg TID-QID PO | 同上 |
| **Propranolol (Inderal)** | β₁ 及 β₂ 腎上腺素受體之拮抗劑（β-blocker） | — | 鴉片戒斷、鋰鹽引起的 tremor、酒精戒斷、攻擊行為、恐慌疾患、抗精神藥物引起的靜坐不能 akathisia（使用時要監控病人之血壓跟心跳）、抗焦慮藥。主要是取其降低心悸效果。 |

## Antipsychotic 適應症

1. **Schizophrenia spectrum disorder**
2. **Mood disorder**：在 mania 與 mood stabilizer 併用可以縮短病程
3. **Tourette's、Autistic disorder**：想成 DA 過多導致運動增加
4. **Psychosis**：dementia with BPSD、substance related、organic problems related、depression with psychotic features 等
5. **Agitation/Violence**：delirium 的症狀，不是治療 delirium
6. **非精神科用途**：止噁心、止吐、運動障礙

## DA Pathway in Brain

Antipsychotics 目標是 ↓ mesolimbic、↑ mesocortical、不影響其他的。

| Pathway | 路徑 | Effect |
|---------|------|--------|
| **mesolimbic** | tegmentum → other limbic structure (olfactory tubercle, nucleus accumbens, amygdaloid complex, piriform cortex) | DA↑ → 正向症狀<br>DA↓ → 無趣 |
| **mesocortical** | tegmentum → limbic cortex (medial prefrontal, cingulate, entrohinal area). 5HT2A | DA↓ → 負向症狀 |
| **nigrostriatal** | substantia nigra → basal ganglia | DA↓ → Parkinson's disease, EPS |
| **tuberoinfundibular** | arcuate nucleus of mediabasal hypothalamus → median eminence | DA↓ → prolactinemia, amenorrhea, sexual dysfunction |
| **Medullar periventricular** | Dorsal motor vagus, nucleus tractus solitarii, periaqueductal, periventricular gray → tegmentum, thalamus, hypothalamus | DA↓ → eating behavior |
| **incertohypothalamic** | Hypothalamus → lateral septal nuclei | 和男性 erection 有關 |
| **medulla oblongata** | 延腦內的 area posteremia | 嘔吐中樞 |

## Antipsychotic 共同作用受器

以下均為抑制該 receptor 所造成之影響：

| 受器 | 副作用 |
|------|--------|
| **D₂ receptor** | 抑制正向症狀 |
| **α₁ adrenergic receptor** | 頭昏、鎮靜、姿態性低血壓等 S/E |
| **Muscarinic 1 cholinergic receptor** | 便秘、尿滯留、口乾、視力模糊等 S/E |
| **Histamine 1 receptor** | 嗜睡、鎮靜、食慾增加、體重增加 |

## EPS (Extrapyramidal Syndrome)

| Type | 高風險族群 | 發生時間 | 症狀 | 治療 |
|------|-----------|---------|------|------|
| **acute dystonia** | 年輕男性 (<40y) | 數小時到數天 | 橫紋肌張力失調〔斜頸、下巴張開、眼睛上吊（Oculogyric crisis）〕 | Anticholinergics (benztropine 1-2mg 或 diphenhydramine 25-50mg IV 或 biperiden) |
| **akathesia** | — | 一週後到數週 | 坐立難安、不停走動、焦躁不安（可以是 inner restless） | Anticholinergic agent (Akineton), Propranolol (30-120mg/d), BZD |
| **parkinsonism** | 女性 (>40y) | 一週後到數週 | Tremor, bradykinesia, rigidity, postural instability | Anticholinergics (diphenhydramine), anti-Parkinson (benztropine, trihexyphenidyl) |
| **tardive dyskinesia (TD)** | 女性、>50y、曾經有腦部傷害、mood disorder | >6 mo，一般 1-2y | 咀嚼肌、眨眼肌、四肢的不規則動作 | 無有效治療，除 risperidone 外皆須停藥 |

> **註：** DA receptor 代償性 ↑ 並成 hypersensitivity。Ingrezza (Valbenazine) 2017 通過 FDA。
