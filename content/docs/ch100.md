# 核醫科檢查及治療

## 心臟血管系統 (王榮福, 林俊良, & 陳熾武, 2008)

### Myocardial perfusion SPECT scan / CAD evaluation

| 項目 | 說明 |
|------|------|
| **Test/Indication** | Myocardial perfusion SPECT scan; CAD evaluation; Persantin禁忌：asthma、HoTN、AMI |
| **Tracer** | Tl-201; Tc-99m MIBI |
| **Mechanism** | Tl-201: +1價，似K⁺ → Na-K pump → 血流多uptake↑且washout↑。Tc-99m MIBI: 脂溶性，擴散入細胞再主動運輸進Mitochondria，因喪失脂溶性而被膜電位keep在細胞（無重分佈），與電子傳遞鏈與實有關，耗氧多的uptake↑。 |
| **Procedure** | Tl-201: Stress: 5 min; Rest: 3-4 h. Tc-99m MIBI: Stress、rest：打藥後1h。於2-3h再次打藥 |
| **Interpretation** | ①比較stress和rest：rest wnl = ischemia; rest↓ = infarction or severe ischemia。Reverse（rest的顯影比較差）：1.嚴重缺血且有collateral, 2.橫膈膜假影 3. Post-MI with viable cell。②gated：接EKG把RR切成6份看EF和wall motion (用影像重組)。③ heart-lung ratio：看HF。 |
| **Notes** | Tl-201: 有redistribution（stress時↓ resting時↑，可進出細胞），只打一次藥。Tc-99m MIBI: 打藥後30min吃東西(lipid, protein)以降低liver顯影（較易區分heart）。 |

### Myocardial infarct scan

| 項目 | 說明 |
|------|------|
| **Test/Indication** | Myocardial infarct scan; AMI dx or prognosis |
| **Tracer** | Tc-99m PYP |
| **Mechanism** | AMI後Ca在壞死心肌中形成經量磷灰石結晶，透過化學吸附和離子交換獲取PYP。 |
| **Procedure** | 3h |
| **Interpretation** | 0：沒有顯影；1：血夜強度；2：肋骨強度；3：胸骨強度；4：>胸骨。正常心肌是0級為主 |
| **Notes** | 發病後10-12h顯影，48-72h最sensitive，2 wk轉為陰性。 |

### Ventricular function test

| 項目 | 說明 |
|------|------|
| **Test/Indication** | Ventricular function test：①算LVEF ②看heart結構, shunt. ③看心臟毒性藥物造成之影響 |
| **Tracer** | Tc-99m + RBC label（體內法）Multiple gated ventriculography (MUGA) = equilibrium，把RR分成32 fraction。 |
| **Mechanism** | 剛打進去是+7價(first pass)，打入還原劑以後變成+4才能label到Hb β chain (pooling)。MUGA就是利用EKG的R wave開啟dynamic紀錄。 |
| **Procedure** | First pass technique：stat, dynamic 30s. Equilibrium blood pool technique: 15-30 min. |
| **Interpretation** | First pass分時間：I = SVC + RA, 1-3s; II = RV + PA, 2-5s; III = lung, 4-7s, < 8s; IV = LA + LV + Ao, 8-12s |
| **Notes** | MUGA在疊加很多RR時的心臟狀況後可得心室壁運動及增厚的情況，還可計算LVEF，傅立葉轉換後有振幅圖（各部位收縮幅度）& 相位圖（各部位運動次序）。 |

### Venography

| 項目 | 說明 |
|------|------|
| **Test/Indication** | Venography：①靜脈阻塞 ②SVC syndrome |
| **Tracer** | Tc-99m RBC label（體內法）; Tc-99m MAA |
| **Mechanism** | 先靜脈注射cold PYP，15至30分鐘後再從靜脈注射free Tc-99m。 |
| **Procedure** | Early：stat, delayed：打Tc後5 min。 |
| **Interpretation** | 綁止血帶壓掉superficial vein |

## 其他顯影製劑

### RBC label 方法

1. 體外法：efficiency 90%，過程麻煩，抽取病人血液，在試管中還原紅血球並標幟放射活性後再注射入病人體內。
2. Modified 體外法：efficiency 85%，看 GI bleeding，注射還原劑後抽取病人血液，在體外標幟放射活性後再注射入病人體內。
3. 體內法：efficiency 80%，venography，ventricular EF，先注射還原劑，隨後注射 Tc-99m petechnetate，在體內進行紅血球之標幟。

### 半衰期 (Half life)

Ga-67 = 78h, Tc-99m = 6h, I-131 = 8.04d, I-123 = 13.2h, Sr-89 = 50.5d, C-11 = 20 min, N-13 = 10 min, O-15 = 2 min, F-18 = 110 min

### I-131 前藥物停用

| 藥物 | 停用時間 |
|------|----------|
| ATD | 3-7 d |
| 含碘製劑 | 2-3 wk |
| 放射性顯影劑 | > 1 mo |
| Triiodothyronine | 1-2 wk |
| Thyroxine | 4-6 wk |

### SUV 公式

$$SUV = \frac{\text{單位重量腫瘤放射性活度 (MBq/g)}}{\text{注射活度 (MBq) / 體重 (g)}}$$

| Radioisotope | Indication | Protocol | Side Effects/Contraindications |
|--------------|-----------|----------|------------------------------|
| Sr-89 | Bone pain (prostate, breast) | 一針即可，3-20d on-set，持續4-15mo，80%有效。 | S/E：WBC, plt↓ (20-30%) 12wk後恢復。禁忌症：WBC<3000、plt<60,000、CKD、under C/T or R/T。 |
