    抗癲癇藥物 (Antiepileptic Drugs)#

    用藥原則#

    • Start low, go slow
    • 單一藥物治療為原則
    • 治療無效定義：使用最大耐受劑量 2-3 個月症狀未改善
    • 突然停藥可能誘發癲癇重積狀態

    抗癲癇藥物分類#

    1. 抑制鈉離子通道 (Na⁺ Channel Blockers)#

    藥物 劑量 說明
    Phenytoin (Dilantin) 200-400 mg/d 非線性藥物動力學。S/E：齒齦增生、多毛、神經病變、骨質疏鬆。治療全身性強直陣攣發作、複雜部分發作。
    Carbamazepine (Tegretol) 400-1200 mg/d 治療複雜部分發作、全身性強直陣攣發作。S/E：骨髓抑制、肝毒性、Stevens-Johnson syndrome。低鈉血症。
    Oxcarbazepine (Trileptal) 600-2400 mg/d Carbamazepine 衍生物。較少肝酶誘導。S/E：低鈉血症。
    Lamotrigine (Lamictal) 100-500 mg/d 需緩慢滴定。治療全身性發作、Lennox-Gastaut syndrome。S/E：Stevens-Johnson syndrome。
    Lacosamide (Vimpat) 200-400 mg/d 新型 Na⁺ channel blocker。

    2. 增強 GABA 作用 (GABA Enhancers)#

    藥物 劑量 說明
    Phenobarbital 50-150 mg/d 長效。為小兒熱痙攣首選。肝臟代謝。S/E：嗜睡、認知障礙。
    Benzodiazepines — 為 acute seizure 第一線用藥。包括 diazepam、lorazepam、clonazepam。
    Tiagabine (Gabitril) 4-32 mg/d GABA 再吸收抑制劑。
    Vigabatrin (Sabril) — GABA transaminase 抑制劑。

    3. 抑制鈣離子通道 (Ca²⁺ Channel Blockers)#

    藥物 說明
    Ethosuximide (Zarontin) 治療 absence seizure（失神發作）首選。劑量 500-1500 mg/d。S/E：腸胃不適、嗜睡。
    Valproate (Depakote) 為廣效抗癲癇藥物，可治療各類型發作。劑量 500-2000 mg/d。S/E：肝毒性、體重增加、畸胎。

    4. 其他機轉#

    藥物 機轉/說明
    Levetiracetam (Keppra) 新型抗癲癇藥物。作用機轉不明。劑量 1000-3000 mg/d。S/E：嗜睡、行為改變。
    Topiramate (Topamax) 多重機轉（Na⁺ channel blocker + GABA enhancer + AMPA antagonist）。劑量 100-400 mg/d。S/E：體重減輕、認知障礙、腎結石。
    Gabapentin (Neurontin) GABA 衍生物。劑量 900-3600 mg/d。S/E：嗜睡、頭暈。

    各類癲癇發作之藥物選擇#

    發作類型 第一線藥物 替代藥物
    全身性強直陣攣發作 (GTC) Valproate, Carbamazepine Phenytoin, Lamotrigine, Levetiracetam
    失神發作 (Absence) Ethosuximide, Valproate Lamotrigine
    複雜部分發作 (Complex partial) Carbamazepine, Phenytoin Valproate, Lamotrigine, Levetiracetam
    肌陣攣發作 (Myoclonic) Valproate, Clonazepam Levetiracetam, Topiramate
    Lennox-Gastaut syndrome Valproate, Lamotrigine Clonazepam, Topiramate

    癲癇重積狀態 (Status Epilepticus) 治療#

    階段 藥物
    0-5 min ABC (airway, breathing, circulation)、Lorazepam 0.1 mg/kg IV
    5-20 min Diazepam 10-20 mg PR 或 Midazolam IM
    20-60 min Fosphenytoin 或 Phenobarbital
    >60 min 維持劑量 phenobarbital 或 propofol/ketamine 麻醉

    抗癲癇藥物共同副作用#

    • 嗜睡、頭暈
    • 認知功能障礙
    • 步態不穩
    • 過敏反應（皮疹）
    • 骨質疏鬆（長期使用）

    抗癲癇藥物與懷孕#

    藥物 風險
    Valproate 最高畸胎風險（神經管缺陷），應避免使用
    Phenytoin 畸胎風險（Fetal hydantoin syndrome）
    Carbamazepine 輕度畸胎風險
    Lamotrigine 相對安全
    Levetiracetam 動物實驗顯示安全，人體資料有限
