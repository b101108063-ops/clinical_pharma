    Parkinson’s Disease 治療藥物#

    病因學#

    Parkinson’s disease 起因於 substantia nigra 的 dopaminergic neurons 退化，導致 striatum 中 dopamine 減少，造成基底核活性改變。

    藥物治療原則#

    1. 早期治療： 視症狀嚴重程度決定是否開始藥物治療
    2. 個體化治療： 根據年齡、職業、生活型態選擇藥物
    3. 長期規劃： 考量運動併發症（motor complications）的發生
    4. 平衡症狀控制與副作用： 「蜜月期」後需調整藥物

    Dopamine 替代/增強劑#

    Levodopa (L-DOPA) + Carbidopa (Sinemet)#

    項目 說明
    機轉 Levodopa 為 dopamine 前驅物，通過 BBB 後轉換為 dopamine。Carbidopa 抑制 peripheral dopa decarboxylase，減少 peripheral dopamine 產生。
    劑量 起始 25/100 mg TID，逐漸調整。長效型 (Sinemet CR) 可減少 motor fluctuation。
    S/E 噁心、嘔吐（peripheral dopamine 作用）、低血壓、心律不整。長期使用：dyskinesia（運動障礙）、motor fluctuation（on-off 現象）、wearing-off（藥效減退）。
    禁忌 狹角性青光眼、精神病。

    Dopamine Agonists#

    藥物 劑量 說明
    Pramipexole (Mirapex) 1.5-4.5 mg/d 非麥角類。D₂/D₃ agonist。S/E：嗜睡（sleep attack）、衝動控制障礙（病態性賭博、購物）。
    Ropinirole (Requip) 3-24 mg/d 非麥角類。D₂/D₃ agonist。S/E：同上。
    Rotigotine (Neupro) 2-8 mg/d 貼片。非麥角類。
    Bromocriptine (Parlodel) 2.5-30 mg/d 麥角類。較少使用。S/E：心包膜/肺纖維化。
    Cabergoline (Cabaser) 1-6 mg/d 麥角類。S/E：心瓣膜纖維化。

    MAO-B Inhibitors#

    藥物 劑量 說明
    Selegiline (Eldepryl) 5-10 mg/d 抑制基底核中 dopamine 分解。早期使用可延緩 Levodopa 需要。S/E：失眠（活性代謝物為 amphetamine）。
    Rasagiline (Azilect) 1 mg/d 選擇性 MAO-B inhibitor。比 selegiline 更強。S/E：頭痛、關節痛。
    Safinamide (Xadago) 50-100 mg/d 新型 MAO-B inhibitor + sodium channel blocker。

    COMT Inhibitors#

    藥物 劑量 說明
    Entacapone (Comtan) 200 mg 每次 levodopa 劑量 抑制 peripheral COMT，延長 levodopa 半衰期。減少 off time。S/E：腹瀉、尿色變黃。
    Tolcapone (Tasmar) 100-200 mg TID 同時抑制 peripheral 和 central COMT。需監測肝功能。

    抗膽鹼藥物#

    藥物 劑量 說明
    Trihexyphenidyl (Artane) 2-15 mg/d 阻斷 striatum 中 muscarinic receptor，改善 tremor 和 rigidity。適用於年輕病人之早期症狀。S/E：口乾、視力模糊、便秘、尿滯留、認知障礙（老年人應避免）。
    Benztropine (Cogentin) 0.5-6 mg/d 抗膽鹼藥物。用於 drug-induced parkinsonism。

    NMDA Receptor Antagonists#

    藥物 說明
    Amantadine (Symmetrel) 100-300 mg/d。增加 dopamine release + NMDA antagonist。治療 Levodopa 誘發的 dyskinesia。S/E：下肢水腫、網狀真皮、幻覺。

    治療策略#

    早期 Parkinson’s#

    病人特性 建議用藥
    年輕 (<65y)，無認知障礙 Dopamine agonist 或 MAO-B inhibitor
    年老 (>65y)，有認知障礙風險 Levodopa (低劑量)
    以顫抖為主 抗膽鹼藥物

    中晚期 Parkinson’s#

    症狀 建議加用
    Motor fluctuation COMT inhibitor 或 MAO-B inhibitor
    Dyskinesia Amantadine 或減少 levodopa 劑量
    Off-time 延長 長效 levodopa 或 dopamine agonist

    特殊考量#

    情況 處理
    精神病症狀 (Psychosis) 避免典型抗精神病藥物。可使用 Quetiapine 或 Clozapine。Pimavanserin (Nuplazid) 為选择性 5-HT₂A antagonist。
    姿勢性低血壓 增加鹽分攝取、彈性襪。可使用 Midodrine。
    憂鬱症 SSRI。避免 MAOI（若使用 selegiline）。
    便秘 軟便劑、增加纖維攝取。
