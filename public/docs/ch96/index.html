    敷料 (Dressings) (Thorne, et al., 2007)#

    吸水力 種類 敷料 附著力 抗菌能力 臨床應用
    弱 Film Tegaderm, OpSite ✓ ✗ 無吸水性，黏附力強，阻絕液體及bacteria。
    Tulle gras 石蠟質敷料 Paraffin gauze dressing ✗ ✓ 石蠟質網狀敷料，常用於附蓋STSG、FTSG等脆弱補皮，亦可用於燒燙傷、擦傷、撕裂傷、DM ulcer、壓瘡、造口等。附著力與吸水性較差，須配合其他敷料使用。
    Fradiomycin patch (Framycin) ✗ ✓
    Antiseptic tulle dressing ✗ ✓ 含Chlorhexidine 0.5%，附著力低，不沾黏傷口，具抗菌功效。
    Chlorhexidine gauze dressing ✗ ✓
    Hydrogel Inrasite ✗ ✗ 含水高 (>95%) 保濕力強，但不具吸水性。不沾黏傷口，換藥時無疼痛感可用於DM ulcer、壓瘡、燒燙傷、撕裂傷，但不適用於嚴重感染傷口含glycerin 延展性高，可用於凹凸不平之傷口表面。
    Silicone Dermatix ✓ ✗ 減少scar組織增生和色素沉澱。
    中 Hydrocolloids Duoderm ✓ ✗ 中等吸水性，常用於skin graft donor site。可3-5天再做更換，但不可用於嚴重感染傷口 (尤其是厭氧菌感染)。
    Foam Allevyn, Tegra ✓ ✗ 中等吸水，透氣，用於滲出液較多的傷口。
    強 Alginate Kaltostat, Sorbsan ✓ ✓ (部分) 高吸收能力，可用於滲出液多的傷口、燒燙傷。部分含銀離子具抗菌效果。
    Hydrocolloids (強) Duoderm Extra Thin ✓ ✗ 高吸收，用於壓瘡、靜脈潰瘍。

    敷料更換頻率 / Dressing Change Frequency#

    敷料類型 更換頻率 備註
    Film (Tegaderm, OpSite) 每3-5天更換 透明可直接觀察傷口
    Hydrocolloids (Duoderm) 每3-5天更換 渗液多時每1-3天更換
    Alginate 每1-3天更換 渗液多時每日更換
    Foam 每2-4天更換 渗液多時每1-2天更換
    Hydrogel 每1-3天更換 傷口乾燥時使用
    Silver sulfadiazine (燒燙傷) 每日更換1-2次 厚敷，需清除前次藥膏
    Mupirocin ointment (Bactroban) 每日2-3次 MRSA感染時使用
    Paraffin gauze (tulle gras) 每1-3天更換 脆弱傷口、燒燙傷

    特殊敷料劑量 / Application Notes#

    敷料/藥物 劑量/用法 頻率 給藥途徑
    Mupirocin ointment 2% 塗抹薄層於傷口 每日2-3次 局部外用
    Silver sulfadiazine cream 1% 塗抹厚層 (1-2mm) 每日1-2次 局部外用
    Chlorhexidine solution 0.05% 沖洗傷口 每次換藥時 局部外用
    Hydrogen peroxide 3% 稀釋一倍後沖洗 每次換藥時 局部外用
    Povidone-iodine 10% 稀釋10-20倍後使用 每日1-2次 局部外用
    Fradiomycin patch (Framycin) 直接貼敷 每1-2天更換 局部外用
