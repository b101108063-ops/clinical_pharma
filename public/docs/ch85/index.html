    CH85 COPD 用藥 (COPD Medications)#

    COPD 治療原則#

    藥物治療目標#

    1. 支氣管擴張 - 放鬆平滑肌，改善氣流
    2. 抗發炎 - 減少氣道炎症
    3. 症狀控制 - 改善生活品質
    4. 預防急性發作 - 減少併發症

    COPD 藥物分類#

    支氣管擴張劑#

    β₂ Agonists#

    分類 藥物 說明 劑量/用法
    SABA Salbutamol (Albuterol)、Terbutaline 急性發作使用 Salbutamol 1-2 puffs q4-6h PRN
    LABA Salmeterol、Formoterol 維持治療，formoterol onset 快 Salmeterol 50μg BID；Formoterol 4.5-12μg BID

    Muscarinic Antagonists#

    分類 藥物 說明 劑量/用法
    SAMA Ipratropium (Atrovent) 短效，急性期常與 SABA 混合吸入 2 puffs q4-6h
    LAMA Tiotropium (Spiriva) 長效，COPD 專用 18μg (1 capsule) QD

    Methylxanthines#

    藥物 說明
    Theophylline 二線藥物，機轉: 抑制 PDE、阻斷 adenosine receptor

    抗發炎藥物#

    吸入型類固醇 (ICS)#

    藥物 說明 劑量/用法
    Fluticasone COPD 不建議長期使用 high dose oral steroid 低剂量 100-250μg BID，中剂量 250-500μg BID
    Budesonide COPD 不建議長期使用 high dose oral steroid 低剂量 200-400μg BID

    聯合治療 (ICS + LABA)#

    藥物 商品名 劑量/用法
    Fluticasone + Salmeterol Seretide 100/50、250/50、500/50 μg BID
    Budesonide + Formoterol Symbicort 160/4.5 或 320/9 μg BID

    黏液調節劑#

    藥物 說明 劑量/用法
    Carbocisteine 具抗氧化及抗發炎效果，RCT (PEACE study): 可減少 COPD 急性發作並提升 QoL 375mg TID 或 1500mg QD
    N-acetylcysteine (NAC) 對穩定的 COPD 病人可提高日常功能 600-1200mg BID-TID

    COPD 急性發作治療#

    藥物 劑量
    Prednisolone 40 mg/day x 5-7 days
    SABA + SAMA 混合吸入
    抗生素 如有感染跡象

    COPD 藥物使用原則#

    穩定期 COPD#

    1. 輕度: SABA PRN
    2. 中度: LAMA 或 LABA + ICS
    3. 重度: LAMA + LABA + ICS
    4. Very Severe: 加上 mucolytic、LTVV

    急性發作#

    1. SABA + SAMA 混合吸入
    2. Systemic corticosteroid
    3. 抗生素 (如需要)
    4. 氧氣治療 (維持 SpO₂ 88-92%)

    COPD 禁用藥物#

    • Long-term oxygen therapy (>15 hrs/day) for chronic hypoxia
    • Narcotics - 會抑制呼吸
    • Sedatives - 會抑制呼吸

    疫苗建議#

    疫苗 頻率
    Influenza vaccine 每年
    Pneumococcal vaccine 每 5 年或依指引
    COVID-19 vaccine 依現行指引
