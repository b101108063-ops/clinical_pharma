    抗病毒藥#

    抗皰疹病毒藥 (Anti-herpesvirus)#

    藥物總覽#

    藥物 適應症 副作用
    Acyclovir (Zovirax) HSV、VZV 腎毒性、神經毒性 (意識障礙)
    Valacyclovir (Valtrex) HSV、VZV、CMV 較少腎毒性
    Famciclovir HSV、VZV 頭痛、噁心
    Ganciclovir (Cytovene) CMV視網膜炎 骨髓抑制 (中性球減少、血小板減少)、腎毒性
    Valganciclovir CMV 同ganciclovir
    Cidofovir CMV視網膜炎 腎毒性、葡萄膜炎
    Foscarnet CMV、acyclovir抗藥之HSV/VZV 腎毒性、電解質異常 (低鈣、低鎂、低鉀)

    劑量參考#

    疾病 藥物 劑量
    唇皰疹 (HSV) Acyclovir 200mg PO 5x/day x 5-10d 或 400mg PO BID
    生殖器皰疹 Acyclovir / Valacyclovir Acyclovir 200mg 5x/d 或 Valacyclovir 1g BID
    水痘 (VZV) Acyclovir 800mg PO 5x/day x 7d
    帶狀皰疹 Acyclovir / Valacyclovir / Famciclovir Valacyclovir 1g TID x 7d
    CMV視網膜炎 Ganciclovir / Valganciclovir / Foscarnet / Cidofovir 誘導期後維持治療

    抗流感病毒藥#

    藥物 適應症 副作用
    Oseltamivir (Tamiflu) A型、B型流感治療與預防 GI不適 (噁心、嘔吐)、頭痛
    Zanamivir (Relenza) A型、B型流感 支氣管痙攣 (吸入劑)
    Peramivir (Rapiact) A型、B型流感 腹瀉
    Amantadine / Rimantadine A型流感 (已多有抗藥性) 中樞神經副作用 (頭暈、失眠)

    抗B型肝炎病毒藥 (Anti-HBV)#

    藥物 特色 副作用
    Entecavir (Baraclude) 第一線選擇之一 乳酸中毒 (有肝毒性風險者)
    Tenofovir (Viread) 第一線選擇之一 腎毒性、骨質減少
    Adefovir (Hepsera) 對lamivudine抗藥者 腎毒性
    Lamivudine (Heptodin) 抗藥性高
    Telbivudine 肌病變

    抗C型肝炎病毒藥 (Anti-HCV)#

    直接抗病毒藥 (DAAs)#

    藥物 特色
    Sofosbuvir (Sovaldi) NS5B抑制劑，泛基因型
    Ledipasvir/Sofosbuvir (Harvoni) 泛基因型，固定複方
    Elbasvir/Grazoprevir (Zepatier) 基因型1,4
    Ombitasvir/Paritaprevir/Ritonavir + Dasabuvir (Viekira Pak) 基因型1
    Sofosbuvir/Velpatasvir (Epclusa) 泛基因型
    Glecaprevir/Pibrentasvir (Mavyret) 泛基因型，8週療程
    Sofosbuvir/Velpatasvir/Voxilaprevir (Vosevi) 泛基因型，用於DAAs治療失敗者

    干擾素製劑#

    藥物 特色
    Pegylated interferon alfa-2a (Pegasys) 每週注射，需與ribavirin合用
    Pegylated interferon alfa-2b (PegIntron) 每週注射

    核苷類似物#

    藥物 特色
    Ribavirin (Copegus) 與干擾素合用，溶血性貧血

    抗愛滋病毒藥 (Anti-HIV) - HAART#

    核苷反轉錄酶抑制劑 (NRTIs)#

    藥物 劑量 副作用
    Tenofovir (TDF)/Tenofovir alafenamide (TAF) 300mg QD / 25mg QD 腎毒性、骨質減少 (TDF)
    Emtricitabine (FTC) 200mg QD 色素沉澱
    Lamivudine (3TC) 150mg BID 或 300mg QD 極少
    Abacavir (ABC) 300mg BID 過敏反應 (HLA-B*5701)、心血管風險
    Zidovudine (AZT) 300mg BID 骨髓抑制、貧血、乳酸中毒

    非核苷反轉錄酶抑制劑 (NNRTIs)#

    藥物 劑量 副作用
    Efavirenz (EFV) 600mg QD 中樞神經副作用 (眩夢)、皮疹、肝毒性
    Etravirine (ETV) 200mg BID 皮疹
    Rilpivirine (RPV) 25mg QD 憂鬱、頭痛

    蛋白酶抑制劑 (PIs)#

    藥物 劑量 副作用
    Ritonavir (RTV) 作為藥效增強劑 GI不適、肝毒性
    Darunavir (DRV) 800mg QD 皮疹、肝毒性
    Atazanavir (ATV) 300mg QD 膽紅素上升、腎結石

    整合酶抑制劑 (Integrase Inhibitors)#

    藥物 劑量 副作用
    Raltegravir (RAL) 400mg BID 肌肉問題、失眠
    Dolutegravir (DTG) 50mg QD 失眠、頭痛
    Bictegravir (BIC) 50mg QD 體重增加

    融合抑制劑/輔助受體拮抗劑#

    藥物 適應症 副作用
    Maraviroc (MVC) CCR5-tropic HIV-1 肝毒性、過敏
    Enfuvirtide (T-20) 注射劑，用於治療失敗病例 注射部位反應、過敏

    固定劑量複方 (Fixed-Dose Combinations)#

    藥物 成分
    Truvada TDF/FTC
    Descovy TAF/FTC
    Atripla TDF/FTC/EFV
    Complera TDF/FTC/RPV
    Stribild TDF/FTC/cobicistat/elvitegravir
    Genvoya TAF/FTC/cobicistat/elvitegravir
    Triumeq ABC/3TC/DTG
    Biktarvy TAF/FTC/BIC

    抗COVID-19藥#

    藥物 適應症 副作用
    Paxlovid (Nirmatrelvir/Ritonavir) 輕中度COVID-19，高風險族群 味覺障礙、腹瀉、肝毒性
    Molnupiravir (Lagevrio) 輕中度COVID-19 腹瀉、噁心
    Remdesivir (Veklury) 住院病人或高風險門診病人 肝毒性、過敏反應

    抗病毒藥物使用原則#

    1. 病毒感染的治療需早期開始，效果更佳。
    2. 抗病毒藥物多有肝、腎毒性，需監測肝腎功能。
    3. 某些抗病毒藥物有致畸胎性，懷孕用藥需審慎評估。
    4. 抗藥性病毒的產生是治療失敗的主要原因之一，需規則服藥。
    5. 雞尾酒療法 (HAART) 可大幅降低愛滋病死亡率。
