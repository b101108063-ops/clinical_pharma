    抗結核藥《結核病診治指引第五版》#

    第一線藥物（均為QD使用）#

    藥物 作用 機轉 代謝 副作用
    Isoniazid (INH, H) 5mg/kg (4-6), max 300mg 杀菌 (僅TB) 抑制細胞壁 Mycolic acid合成 肝臟代謝 (N-acetyltransferase) ↑ P450 肝毒性 (AST/ALT↑，age相關，4-8 wks post-tx)、末梢神經毒性 (和pyridoxal phosphate競爭apotryptophanase, Vit.B6預防)、lupus-like symptom。
    Rifampin (RIF, R) = rifampicin (RMP, R) 10mg/kg (8-12), max 600mg 廣效杀菌 抑制DNA-dependent RNA polymerase；脂溶性高。 ↑p450，和HAART易有交互作用 肝毒性 (bilirubin↑)、橘紅尿 (代謝物顏色)、臉胎、hemolytic anemia。禁忌症：紫質症
    Ethambutol (EMB, E) 15mg/kg (15-20), max 1600mg 抑菌 (僅TB) Quinolone類 (抑制DNA gyrase) 腎代謝。CNS穿透差。每個月看視力及辨色力 視神經炎 (retrobulbar neuritis紅綠色盲，blurred central scotoma) → 小孩 (<6 y/o，因為不會complaint) 禁用，若立即停藥可恢復。CKD會提高發生率。
    Pyrazinamide (PZA, Z) 25mg/kg (20-30), max 2000mg 杀菌，組織穿透力佳 進入macrophage內的phagosome杀菌，僅對胞內結核有效。 pH<5時具活性 肝毒性、高尿酸、polyarthralgia、血糖↑。
    Streptomycin (SM) 0.75g/次，總劑量<120g 杀菌 Aminoglycoside (inhibit 30S) 耳毒＞腎毒、骨骼肌鬆弛。

    複方藥#

    藥物 成分 用法
    Rifinah (RFN) RFN300 = INH 150mg + RIF 300mg, RFN150 = INH 100mg + RIF 150mg >50kg: 300x2, <50kg: 150x3
    Rifater (RFT) INH 80mg + RIF 120mg + PZA 250mg 1#/10kg, max 5#
    AKuriT-4 INH 75mg + RIF 150mg + PZA 400mg + EMB 250mg 30-37 kg: 2#, 38-54 kg: 3#, 55-70 kg: 4#
    AKuriT-3 INH 75mg + RIF 150mg + EMB 250mg 271 kg: 5#

    抗結核藥物對結核菌之效力#

    • A族群： 快速生長，active cavity，傳染力最強 → INH > SM > RIF > EMB。
    • B族群： 慢速生長，躲在macrophage裡面 → PZA > RIF > INH → 故早期要用PZA。
    • C族群： 偶爾生長 → RIF > INH。

    第二線藥物#

    Levofloxacin, moxifloxacin, Amikacin, Para-aminosalicylate (PAS), Cycloserine, kanamycin, capreomycin, rifabutin (RFB)：①僅用在吃HAART的HIV病人。②對RMP有抗藥性。③對RMP有副作用。

    Rifapentine (RPT)：S/E同RMP，在low TB burden治療效果和RMP一樣，故用來治LTBI。

    抗藥性定義#

    1. Multi-drug resistance (MDR-TB)： 同時對INH、RIF具抗藥性。

    2. Poly-drug resistance (PDR-TB)： 對超過兩種anti-TB具抗藥性，但對INH、RIF不同時具抗藥性。

    3. Chronic case： 在DOTS下接受完整二線藥治療依然痰細菌學positive；或對大多數一線、二線藥有抗藥性導致無效治療；或因嚴重藥物S/E而無法治療者。

    4. Extensively drug-resistant tuberculosis (XDR-TB)： 對INH、RIF以及對任何一種fluoroquinolone以及對以下三種可注射使用的二線藥至少一種有抗藥性 (amikacin、kanamycin、capreomycin)。

    治療結果#

    1. ** Cure：** 治療過程中至少一次痰陰性，且治療之最後一個月時痰陰性。

    2. 完治 (treatment complete)： 已完成治療但缺乏痰檢體故無法歸類者。

    3. 失敗 (failure)： new case治療第五個月依然positive；retreatment case治療最後依然positive；或治療前negative但是治療2個月後變成positive。

    INH使用pyridoxine (25-50mg QD)條件#

    DM、CKD、poor nutrition、seizure、pregnancy、breast feeding female、alcoholism、HIV patient。

    治療時間#

    New case#

    HERZ x 2 months + HER x 4 months，或者HER alone x 9 months（嚴重痛風或年紀大而無法用Z）。若證實INH及RIF無抗藥性即可停用EMB，若無結果則須全程使用EMB。最短治療時間為180天，另PZA要使用滿60天。

    Retreatment case#

    (過去曾接受 >4 week的治療，抗藥性增加2-5倍)：(HERZ+SM) x 2 months + HERZ x 1 months + HER x 5 months，除非可以prove新的TB對原本的藥物有效。

    Latent TB infection#

    ① INH + pyridoxine 25mg qd x 6-9 months if INH sensitive。② RIF x 4 months if INH resistant。③ INH + RPT QW x 3 months if INH & RMP sensitive。可降低15個月後70-80% TB發生率。目前推行所有人都要治療。

    Extrapulmonary TB#

    若為meningitis/miliary TB，使用抗TB藥物12 month。若為bone TB則要治療9個月。其餘照一般治療。

    Meningitis/pericarditis要加用steroid：60mg QD x 4 wk → 30mg QD x 4 wk → 15mg QD x 2 wk → 5mg QD x 1 wk。

    治療中斷#

    1. 在前兩個月中斷超過14天要重新計算天數，在兩個月之後中斷若超過3個月也要重新治療。

    2. 停藥 < 2 month → 維持原藥吃回去。停藥 > 2 month → 要檢驗TB抗藥性，在結果出來之前上HERZS。

    抗藥性或S/E之改藥#

    1. RIF抗藥： HEZ x 18 month。

    2. EMB抗藥： HRZ x 2 month + HR x 4 month。

    3. INH抗藥（不管是high dose或low dose）： RZE ± H x 6-9 month 或 HERZ x 2 month + HER x 7 month，使用後者要確保treatment response好。要注意INH的血清濃度遠大於藥敏的MIC，所以可以續用INH但是不能算是有效藥物。

    4. PZA抗藥： HR x 9 month。

    5. 兩種以上抗藥或S/E： 請參考《結核病診治指引第五版》作調整。

    肝腎功能不好#

    腎功能不好 (Ccr<30ml/min)#

    HR不用動，EZ改QOD。如果在洗腎，則EZ改TIW（洗腎後給藥）。

    肝功能不好#

    • Acute hepatitis：不能用藥。
    • Chronic、hepatitis或cirrhosis：先觀察7-10天，如果穩定可開始給RES x 7-10天，若惡化要換成HES，若無變化可用HRES。HRES用了之後若惡化要換成RZES，如果穩定則用HRE。

    懷孕#

    HERZ可用，另外要加Vit B6。哺乳可用HERZS，母乳中藥物濃度很低。
