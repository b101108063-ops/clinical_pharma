    飲食處方 (Dietary Prescriptions)#

    管灌飲食及其演變 (Klingensmith, Aziz, Bharat, Fox, & Porembka, 2012)#

    1. 一般管灌 Tube Feeding：為病患無法經口給食或經口給食營養不足時所用。原則上都是 1 kcal/ml，因此在受限水的病人就必須要調整，如 1.5 kcal/ml 或 1.8 kcal/ml。

    2. 成分分成：聚合食 (Polymeric Diet)、元素食 / 預解食 (Elemental Formula / Partially Hydrolyzed Formula)。

    3. 灌食方法分成：bolus feeding 及 continuous feeding 兩種。

      • (1) Bolus feeding：一般給 240-360 ml Q4H。頭要抬高 30-45 度，餵食後 1-2 小時才能平躺。每次餵食完要用 30ml 的水沖洗餵食管路。每次餵食前要先反抽，如果剩餘量超過前一次灌食量的 50%，要延後灌食。
      • (2) Continuous feeding：一般從 20ml/hr. 開始，以每 4-6 小時調高 10-20ml/hr，直到達目標灌食流速。每 4 小時要用 30ml 的水沖洗餵食管路。如果發生腹脹或疼痛，考慮降低灌食速度。在某些病人身上，可以僅用晚上 8-12 小時灌完整天的量，這樣病人白天可以活動。

    新生兒飲食#

    1. Fluid：目標 130-159 ml/kg/day，分 Q3H。起始給法 term 60 ml/kg/d -> 80 -> 100, preterm 70 -> 90 -> 110（因為早產兒水分散失比較多），每天增加 10-20ml/kg/day。

    2. 熱量：目標 Preterm：110-130kcal/kg/day；Fullterm：90-110kcal/kg/day。母乳 0.66 kcal/ml，formula 0.8 kcal/ml。fortifier 3.5 kcal/package，為母乳添加劑，足量是 25ml 母乳 +1 pack = 0.8 kcal/ml。

    3. Iron：添加條件 222 (BW*2 or 2m/o or BW 2kg)，1 GTT=2.5mg，預防 IDA 24mg/kg/day，治療 IDA 46mg/kg/day。

    4. Honeybear = multivitamin (intake>25ml，fortifier 兩天沒問題後才加)：0.1 → 0.5ml/kg/day BID。

    決定 TPN 的步驟#

    1. 決定總熱量
    2. 決定 protein
    3. 決定 lipid
    4. 用 glucose 補不夠的熱量
    5. 算 electrolyte
    6. 決定 trace element 和 vitamin 添加

    Insulin#

    初期給予 TPN 可以先用一般 MDII 控制血糖，當比較穩定時，可以在營養注射液中加入 RI，起始劑量為 2/3 TDD。目標血糖 100-200 mg/dl。

    停止靜脈營養#

    當病人 enteral feeding 到達 75%的 total daily calorie 即可以停止 TPN，而在病人進食進步過程中，營養成分可以逐漸降低。建議每小時流速減半，在 4-6 小時才完全停止，如此可以降低病人因 hyperInsulinemia 導致 rebound hypoglycemia 發生之機率，但在 < 1000kcal/day的病人可以直接停掉。
